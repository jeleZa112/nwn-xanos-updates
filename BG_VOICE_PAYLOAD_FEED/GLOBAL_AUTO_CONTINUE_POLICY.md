# BG Voice RU — GLOBAL_AUTO_CONTINUE_POLICY_R1

Дата фиксации: 2026-11-22. Приоритет: обязательное рабочее правило проекта, обе ветки чатов.

**После любого положительного результата (PASS) автоматически переходить к следующему безопасному конкретному этапу в рамках текущей активной работы, если действий пользователя не требуется. Не заканчивать ответ просто потому, что завершилась одна версия, пакет, тест или публикация. Не просить «+», «продолжай», переприкрепить файлы, запустить другой CMD или передать ZIP между чатами, когда это не требуется.**

## Рабочий цикл

1. Проверить текущую правду: опубликованные версии, основные отчёты и реальные результаты Windows; не считать синтетический PASS подтверждением Windows/актерской пригодности.
2. Выбрать следующую незавершённую **полезную** задачу: производство WAV, проверка качества выбранного дубля, защита известных решений, интеграция в один основной updater. Не плодить диагностику ради отчёта.
3. Выполнить этап, проверить выход, сохранить SHA256, дописать контрольную точку в проект, переходить к следующей доступной безопасной задаче.
4. Ошибка одного WAV или источника: HOLD + очередь повтора, остальные задания продолжаются.
5. Завершать текущий ответ только при объективном блокере (отсутствие нужного локального Windows GPU/диска, человеческое прослушивание, изменение игры/деструктивная установка требующие одобрения, ошибка безопасности), либо когда не осталось доступных безопасных действий в этом сеансе. В итоговом ответе назвать точный блокер, а не выдать неопределённое «что дальше».

## Ответственность двух чатов

- **Voice-поток:** делает безопасные исходные задачи, публикацию модулей/CSV, проверки и общий индекс в `bg-voice-payloads`. Не изменяет рабочий `BG_VOICE_UPDATE.cmd` соседнего потока.
- **Основной поток:** один `BG_VOICE_UPDATE.cmd`, сборка и запуск под Windows, одно дерево `FULL_PRODUCTION`, один `SEND_TO_CHATGPT_BG_VOICE_RU.zip`, сюжет/видеоролики и реальные тесты. Читает shared feed сам, не заставляет пользователя пересылать пакеты.
- Общий индекс: `BG_VOICE_PAYLOAD_FEED/manifest.json` в GitHub ветке `bg-voice-payloads` + `/BG_VOICE_RU/CURRENT/` в ChatGPT Library.

## Безопасность и реализм

- Ни один ASR/ECAPA/числовой PASS не является окончательным пользовательским подтверждением голоса, ударения или актёрской подачи.
- Только SHA-проверенные источники; исходные EN/RU WAV не менять; стадии — в отдельных staging-папках. Нет молчаливой смены Stable/Per_line.
- Все ручные решения защищены, в частности OH85856=V65 PASS, OH80404=V60 PASS, OH89888=BOTH_BAD HOLD. KORGAN57 — исторический конфликт HOLD.
- Запрещено объявлять установленными V70/V71/V73/V74 или rolling только на основании GitHub-публикации.
- Запрещено обещать фоновую постоянную работу вне активного выполнения: между обращениями задачи запускаются только действующим автономным Windows updater или отдельно созданной пользователем автоматизацией.
- **При положительном результате выполняй следующий безопасный шаг без ожидания согласия.**
