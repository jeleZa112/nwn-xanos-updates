# BG Voice RU — продолжение массовой работы без пересылок

Этот пакет **дополняет уже выполненные 420/420 V70**, не повторяя их и не создавая другой Windows-обновлятор.

## Что действительно подготовлено

- `VOICE_BACKED_613_STAGE_ONLY.csv`: 613 **новых** кандидатов из 111 групп персонажей; 590 Per_line и 23 Stable. Точное совпадение RU ASR выбранного дубля в сохранённых отчётах, не меньше 0.90 у альтернативного, 3 старых опорных голосовых образца, разница старых голосовых показателей >=0.10; без акустических предупреждений и ручных защит.
- `NEXT24_VOICE_AB_SHA_GATED.csv`: 24 ранее выявленных сомнительных дубля для слепого прослушивания, **0** повторов из уже готового `V70/QA_NEXT12`.
- `BGVOICE_ROLLING_CONTINUATION.py`: рабочий модуль, который при вызове из **единственного существующего** `BG_VOICE_UPDATE.cmd` создаёт только SHA-проверенные копии WAV, готовит HTML для 24 A/B и продолжает другие записи при ошибке. Повторный проход переиспользует совпадающие копии; испорченные не переписывает.
- `MANIFEST.json`: точные SHA256 и размеры обоих CSV. Подмена данных — немедленный STOP до чтения звука.

### Проверки

- Все 7206 строк V55/V70 сопоставлены по `sound_id`; у 613 кандидатов SHA и путь V55 совпадают с V70.
- 613 пересекаются с 420 V70 на **0** строк, с пользовательскими защищёнными репликами — **0** строк.
- `SELFTEST_ROLLING.py`: чтение 613/24, контроль манифеста, ошибки SHA, пропуск источника, отсутствие записи в игру PASS.
- `SELFTEST_SUCCESS_AND_RESUME.py`: 2 успешных синтетических WAV, один образец A/B, повторное использование 2/2, блокировка испорченного staged WAV без перезаписи, неизменность источников PASS.

## Интеграция — владелец один главный чат

1. Главный чат самостоятельно получает пакет из Библиотеки ChatGPT `/BG_VOICE_RU/CURRENT/BG_VOICE_RU_ROLLING_CONTINUATION.zip` или публичные отдельные исходники с отдельной ветки GitHub `bg-voice-payloads`.
2. Сверяет GitHub-манифест SHA256, и только затем импортирует `BGVOICE_ROLLING_CONTINUATION.run(package_dir)` в **существующий** поток `BG_VOICE_UPDATE.cmd`. Отдельные CMD, PS1, ручные запуски Python пользователем запрещены.
3. Результаты `VOICE_CONTINUATION_STATUS.json`, `VOICE_BACKED_SECOND_PASS/STAGING_STATUS.csv`, `VOICE_AB_NEXT24/QA_STATUS.csv` добавляет в **один** `SEND_TO_CHATGPT_BG_VOICE_RU.zip` в `C:\Users\Drevo\Documents\BG_VOICE_RU\FULL_PRODUCTION`. Можно показать `OPEN_REVIEW.html` после подготовки звука.
4. Продолжает безопасные этапы после PASS, сохраняет предыдущие отчёты и рабочие ветки видеозаставок. HOLD отдельного WAV не блокирует остальные.
5. Нет установки в игру, изменения исходных WAV или изменения пользовательских голосовых решений. `OH85856=V65`, `OH80404=V60`, `OH89888=BOTH_BAD` и `KORGAN57=HOLD`.

**Нельзя объявлять эти 613 художественно одобренными:** ASR и старые голосовые метрики лишь предлагают дубль. Нужны слушательская проверка узнаваемости персонажа, эмоции и целостности выбранного варианта, затем ударения/имена. Настоящая Windows/GPU проверка ещё не произведена. Этот пакет source-only until main updater integration.
