# BG Voice RU — восстановленные модели для выбора Stable/Per_line

**Основная задача** — выбрать лучший из двух существующих WAV для каждого из 7206 Sound ID. До этого стресс/ретейки заблокированы.

Общий SHA-проверенный итоговый пакет (не заменяет game WAV, не содержит новых моделей):
`/BG_VOICE_RU/CURRENT/BG_VOICE_RU_SELECTION_MODEL_EVIDENCE_FUSED.zip`

SHA256: `c00169c4c5e3196865445e9f1ca3b42b80f675e5aeda812cd88df73c8d5f9b2c`
Размер: 3022501 байт.

## Что подключено из уже выполненных экспериментов

- V5 / V55: ASR Faster-Whisper, базовые голосовые признаки ECAPA, audio source SHA (есть исторический `REPORT_EXAMPLE` — не считать новым LIVE запуском).
- V6.4: SpeechBrain ECAPA GPU-подсказки; из V14 восстановлены 87 независимых конфликтов ASR↔ECAPA.
- V7: Silero VAD на 120 парах (ритм/паузы, не актёрское качество).
- V9: TeraAnaly EmotionHead на 6907 парах; 2127 различий категории Stable/Per_line, сильный bias `angry`. **Не выбирать дубль по названию эмоции.**
- V13.1: Zipformer независимый ASR для 247 пар; 17 речевых подсказок, НЕ победители.
- V3: 20 EN SER `superb/wav2vec2-base-superb-er` + 10 отдельных сравнений английских реплик из ранее импортированной SQLite. Это НЕ русский Stable/Per_line выбор.
- V17: все 12 пользовательских оценок, обе русские SHA для всех 12 совпали с полным реестром: 8 предпочтений, 2 BOTH_BAD, 2 NO_EN. Они важнее моделей, не означают финальное одобрение игры.
- STRESS10: 194 словесных записи найдены в SQLite; правильно оставлены до выбора дубля.
- Shtorm/VoxCPM2: инструмент генерации потенциальных исправлений, **не** модель оценки лучшего из существующих двух голосов.

**Ошибка старого реестра:** `BG_VOICE_RU_SELECTION_FIRST_MASTER.zip` объединял только V5/V55/V70/V74; V3/V7/V9/V13/V17 не входили как отдельные данные, и некоторые прежние человеческие предпочтения остались в HOLD. Новый `VOICE_SELECTION_MASTER_7206_MODEL_FUSION.csv` сохраняет все 7206 исходных Sound ID и восстанавливает эти свидетельства.

Человеческие V17 привязаны по Sound ID+SHA256; `OH88513`, `OH81582`, `TIAXX40`, `DYNAH32` более не выпадают из списка уже высказанных предпочтений.

**Не сделано:** новый синтез, Windows-геймплей, прослушивание всех WAV, валидированная автоматическая оценка актёрского качества. Машинные подсказки не утверждены как лучшие. Нужна настоящая калибровка голосового и эмоционального выбора с EN оригиналами и утверждёнными персонажными эталонами. Реальные EXTERNAL ZIP для части старых моделей могут отсутствовать: первичная V3 SER восстановлена из исторической SQLite, но отдельный ZIP V3 здесь не перепроверялся.

**Использовать эту базу, а не предыдущий неполный мастер.** При следующем PASS — продолжать selection-first, без запроса "+" и без ретейков.
