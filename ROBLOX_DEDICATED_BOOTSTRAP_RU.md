# ROBLOX — отдельный физический ПК: единый загрузчик

Последний подтверждённый тест на основном ПК: V3.6.9, три отправленные фоновые W, три NO_MOTION. PostMessage не обеспечивает работу в фоне. Не повторять этот тест.

Новая точка входа `ROBLOX_DEDICATED_BOOTSTRAP.cmd` скачивает существующий `ROBLOX_UPDATE.cmd` из GitHub в `Documents\\ROBLOX_BG_AI`, поверх него updater скачивает `roblox_monitor.py` и проверяет синтаксис и версию. Зафиксирован `ROBLOX_BG_INPUT=0` — ввод только в активный Roblox. Нет установок драйверов и нет фонового ввода в другие приложения.

Работает только на **отдельном физическом компьютере с Windows, Roblox Player и Python**. Для разрешения запуска пользователь явно передаёт `--dedicated-host`. Без этого параметра файл ничего не устанавливает и не запускает.

Для обычного основного ноутбука независимое фоновое управление **не реализовано**. На основном ПК этот загрузчик запускать не нужно. Два монитора или виртуальные рабочие столы Windows не дают независимых потоков ввода; виртуальная машина остаётся неподтверждённой и не рекомендуется как готовое решение.

Реальный прогон режима 15 на отдельном устройстве, прохождение City/1/Hard, навигация и турели пока не подтверждены. Логи: `Documents\\RobloxBGDiagnostics\\AUTOPILOT\\AUTOPILOT_LOG.txt`. F10 остановка при активной игре.

Единственная пользовательская операция на отдельном игровом ПК: скачать файл и выполнить `ROBLOX_DEDICATED_BOOTSTRAP.cmd --dedicated-host`, затем 15 и YES. Не требовать новых OBS-записей и множества отдельных проверок.
