# BGXAI — постоянный обновлятор EET

**Тестовый канал:** v0.6.15-cover-state-pilot (экспериментальная версия, не стабильный релиз).

1. Оставьте один файл `BGXAI_UPDATE.cmd` рядом с `chitin.key` в корне установленной EET.
2. Закройте игру и дважды щёлкните по `BGXAI_UPDATE.cmd`. Нужен интернет.
3. Программа читает `BGXAI/latest.json` из отдельной ветки `bg-eet-ai`, скачивает пакет, проверяет SHA256, делает резервную копию исходников и запускает WeiDU.
4. В последующие разы запускайте **тот же самый файл**, новые одноразовые CMD скачивать не нужно.
5. У Халида выбирайте сценарий `BGXTANK`, у Джахейры — `BGXGRP`. Проводите испытания на отдельном сохранении.

## Что пишется в журнал

`BGXAI_UPDATE.log` появляется в корне игры и содержит **только журнал обновления/установки**: версия, проверка пакета, запуск WeiDU, ошибки. Это **не** журнал боевых действий.

Полноценный `BGXAI_COMBAT.log` с каждым действием и состоянием персонажей пока **не реализован**. Для него требуется отдельная проверенная интеграция с EEex/LuaJIT; текущие BAF-сценарии выводят лишь некоторые диагностические события в игровой текст.

## Ограничения

v0.6.15 всё ещё содержит известную проблему: Джахейра прекращает отступление у танка даже при продолжении преследования волком. Сам факт загрузки обновления **не исправляет её**. Интеграция проверена по GitHub-исходникам и SHA256 архива, но не проверялась в работающей Windows EET/WeiDU в этой среде.

Содержимое ветки `main` для NWN не меняется.
