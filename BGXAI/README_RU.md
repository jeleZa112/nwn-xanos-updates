# BGXAI GitHub updater — beta pilot

Автономный ИИ для Baldur's Gate: Enhanced Edition Trilogy (EET) с SCS 35.21. Разработка отделена от NWN и хранится в изолированной ветке `bg-eet-ai` существующего репозитория GitHub пользователя (ветка `main` с NWN не меняется).

## Как запустить

Скачайте `BGXAI_UPDATE.cmd` и положите в корень EET рядом с `chitin.key`. Закройте игру. Запустите CMD двойным щелчком. Он получит актуальную ревизию из GitHub, скачает BAF/TP2, проверит SHA256, сделает копию предыдущих файлов и запустит WeiDU. Исходный `setup-stratagems.exe` не изменяется.

Первое обновление устанавливает **экспериментальный пилот 0.6.0**, НЕ все запланированные функции v0.7.x. Для теста назначьте только `BGXATK` одному персонажу в отдельном сохранении. При ошибке сохраните скриншот окна и `setup-BGXAI.DEBUG`.

## Что изменяется

Только файлы `BGXAI/*`, устанавливаемые через WeiDU сценарии `scripts/BGX*.BS`, отдельный `setup-BGXAI.exe`, журнал WeiDU. Не изменяет чужие TP2, сюжетные диалоги, CRE или AI врагов. Не публикует архивы пользовательской сборки или файлы игры.

## Откат

WeiDU позволяет удалить компонент BGXAI отдельно через `setup-BGXAI.exe`. Перед тестом создайте отдельное сохранение в игре; прежние исходники BGXAI копируются в `%LOCALAPPDATA%\BGXAI_UPDATER\backup_*`.

Скрипты пилота ещё не были скомпилированы и проверены в установленной EET пользователя. Это тестовый канал.

## Версия 0.6.1-safety-pilot (01.11.2026)

При первом игровом тесте BGXATK на Джахейре её HP упали до 3/53: ожидаемо, т.к. BGXATK не умеет убегать. Добавлен ОТДЕЛЬНЫЙ экспериментальный профиль BGXSAFE (старый BGXATK не изменён):

- при HP <35% ставит локальный режим отступления;
- если виден враг на дистанции <14, выполняет ограниченный отход внутри локации;
- не возвращается к автоатаке до HP >65%, исключая цикл отход/нападение;
- вне боя может лечить себя CLERIC_CURE_MODERATE_WOUNDS / CLERIC_CURE_LIGHT_WOUNDS, только если реально заучены;
- не использует дорогую магию, AoE, предметы, бафы, не трогает других NPC.

Для первого теста подготовьте на Джахейре «Лечение умеренных ран» (2 круг), «Лечение лёгких ран» (1 круг) по одному; остальные заклинания можно оставить для ручного теста. Создайте отдельное сохранение, остановите игру, запустите прежний BGXAI_UPDATE.cmd, после установки назначьте Джахейре «НАСТРОЙКИ (BGXSAFE)».

**Ограничения**: отступление не гарантирует безопасного пути, может временно перебивать ручную команду при критическом HP. Если нужно полностью управлять персонажем вручную, выключите партийный ИИ. Реальная работа BGXSAFE ещё не подтверждена компиляцией на компьютере пользователя или боевым тестом.
