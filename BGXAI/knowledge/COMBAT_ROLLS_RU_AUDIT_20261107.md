**Вывод:** базовые игровые сообщения уже переведены; нельзя бездумно применять `STRING_SET` по этим номерам: в EET встречаются дубликаты из разных кампаний и модификаций; у пользователя есть LeUI, EPS, SCS и русификаторы. Переводить нужно точно установленные англоязычные фрагменты, после проверки текущих ресурсов и происхождения каждого сообщения.

Среди коротких (<180 символов) строк *этого* архива `dialog.tlk` не обнаружены английские строки `Attack Roll`, `Damage Roll`, `Roll:`, `DamageMod` или `Attack Bonus`. Это **не доказывает**, что их нет в игровом боевом журнале: подробные формулы могут формироваться непосредственно движком/GUI, а не отдельными фразами TLK. Нужна проверка происхождения этого текста перед модификацией.

## Как читать расчёт атаки по AD&D 2e

1. Бросок **d20** — число от 1 до 20.
2. Сумма модификаторов к попаданию отражает оружие, характеристики, специализацию, эффекты, состояние и прочие факторы. Если журнал показывает `11 + 3 = 14`, то **14 — модифицированный бросок**, не КД врага и не THAC0.
3. При базовом расчёте атака попадает, когда `бросок d20 + модификаторы >= THAC0 атакующего − эффективная КД цели`. Например, THAC0=17, КД=0: нужна сумма >=17; сумма 14 — промах. THAC0=17, КД=4: нужна сумма >=13; сумма 14 — попадание. Природная 1 всегда промах, природная 20 всегда попадание по штатным правилам.
4. **THAC0 (ТХАК0)** — какое значение нужно выбросить для попадания по КД 0. Чем **меньше** THAC0, тем выше точность. **КД (AC, класс доспеха)** — чем **меньше**, тем выше защита.
5. Уточнение: фактический движок может разносить некоторые бонусы атаки в показатель THAC0, а не во второе слагаемое строки. Не нужно учитывать один и тот же эффект дважды при чтении журнала.

## Предлагаемые русские обозначения для будущего игрового модуля

| Английское обозначение | Русское отображение | Смысл |
|---|---|---|
| Attack Roll / Roll | Бросок атаки / бросок d20 | Выпало на двадцатигранном кубике |
| Attack Bonus / Hit Bonus | Бонус попадания | Суммарный бонус к результату броска |
| THAC0 | THAC0 (ТХАК0) | Порог попадания по КД 0, меньше — лучше |
| Armor Class / AC | КД (класс доспеха) | Защита цели, меньше — лучше |
| Target AC | КД цели | Эффективная КД против данного удара |
| Required Roll | Необходимо для попадания | Сколько нужно после учёта THAC0 и КД |
| Hit / Miss | Попадание / промах | Результат проверки |
| Critical Hit / Critical Miss | Критическое попадание / критический промах | Особые результаты d20 |
| Roll (damage) | Бросок урона | Выпавшее значение урона оружия |
| DamageMod | Модификатор урона | Дополнительное влияние умений и эффектов |
| Strength / STR | Сила | Влияние характеристики |
| Dexterity / DEX | Ловкость | Влияние характеристики |
| Weapon / Enchantment | Оружие / зачарование | Влияние оружия и магического бонуса |
| Proficiency | Владение оружием | Навык или специализация |
| Fighting Style | Стиль боя | Бонус выбранного стиля |
| Luck | Удача | Модификатор удачи |
| Ranged Attack | Дальняя атака | Бросок из дальнобойного оружия |
| Offhand | Вторая рука | Атака неосновной рукой |
| Saving Throw | Спасбросок | Бросок сопротивления эффекту |
| Penalty | Штраф | Ухудшение результата |

**Важное ограничение:** английские термины — словарь для перевода, а не доказанные точные названия всех полей в установленной версии Extra Combat Info.

## Что делать дальше разработчику

- **Не** менять глобальный `dialog.tlk`, `dialogf.tlk`, `UI.MENU`, `BDDEFAI.BCS` ради русификации до аудита места генерации конкретных английских фрагментов.
- Использовать уже установленный `Reveal Hidden Gameplay Options`: опция **Show extra combat info** / `('Game Options','Extra Combat Info','1')` выводит развёрнутые модификаторы; стандартное отображение бросков включается в Gameplay → Feedback → Feedback Messages.
- По реальному игровому примеру точно установить, что является текстом TLK, что GUI, а что формирует движок. Только потом выпускать отдельный opt-in 041 через **существующий** `BGXAI_UPDATE.cmd` с проверкой источника, резервной копией, отчётом и однозначным откатом.
- Модуль 040 отображения F отдельно: никаких общих изменений с будущей русификацией делать нельзя.
