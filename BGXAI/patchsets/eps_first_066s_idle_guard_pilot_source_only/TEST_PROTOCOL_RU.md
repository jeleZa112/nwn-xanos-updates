# Критерии первого A/B испытания (не команда к запуску)

**База A:** точная текущая 066S. **Кандидат B:** только `M_BX43_066S_IDLE_GUARD_CANDIDATE.lua`, без изменения BCS/EPS. Пока НИ ОДНА игра не менялась.

1. Защитники в слотах партии 4 и 5 имеют F=ВКЛ, здоровье >50%, одинаковая область. Первый стоит ближе к магу, но выполняет EPS автоатаку; второй свободен. Противник реально попадает по магу. Ожидаемо: в A выбирается ближайший, который может не суметь среагировать из-за `ActionListEmpty()`; в B при наличии возможности реагирует второй. Это гипотеза, требующая игрового подтверждения.
2. Оба защитника заняты: B не делает новых принудительных действий, оставляя предыдущую логику.
3. Оба свободны: B выбирает ближайшего, как A.
4. F=ВЫКЛ хотя бы у второго: он не выбирается.
5. Ручные приказы, EPS бафы, лечение, предметы, песни, обнаружение ловушек не прерываются.
6. SHA live Lua после обратного удаления экспериментального компонента = `50640902ec4c25a2c85e5088d7231678b54445a847b41743c476974236d1d70f`; BCS = `fb435d82e6c3e0ebea1d6a9532753921bd5411d70ac0677dc1fd8ec483380476`.

**STOP:** любое прерывание ручного приказа, нарушение EPS, ошибка Lua/EEex, неверный F, несовпадение HASH, необратимость бэкапа. Не проводить установку без отдельного согласия.
