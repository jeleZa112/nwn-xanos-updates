# BGXAI — единый автообновлятор, AOE / Entangle READ ONLY

Версия `0.3.43-BGXAOE-READONLY` (17.11.2026).

Использовать **только прежний `C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd`**, пункт **117**. Отдельные CMD/архивы запускать не требуется: они нарушают правило пользователя «один файл».

117 автоматически загружает три исходных файла по SHA256 из pinned-commit, запускает `BGXAI_AOE_AUDIT.py` как внутренний модуль. Скрипт проверяет точный установленный `BGXP5`:
- BDDEFAI.BCS SHA256 `cfc61cfdf7e6ff074a3c26b1e11996a29e6f58fa32d2ddc568866f458b7ac22a`, 1170 блоков
- M_BX43.lua SHA256 `74ddc016e15fae3451bafe3039b299740c9d2efae8ecfb3e86badea257fa650c`
- последний компонент WeiDU — BGXP5, русский `dialog.tlk`, действующий WeiDU EPS

Копирует бинарные данные в изолированную временную папку, декомпилирует **там**, сверяет число блоков и создаёт ZIP `Documents\BGXAI_LIVE_REPORTS\BGXAI_AOE_SEND_TO_CHATGPT_...zip`. Пользователь присылает ZIP в чат. Диагностика **не устанавливает** мод и не меняет BCS, Lua, WeiDU.log, BG_EET_RU, BG Voice RU и сохранения. Автообновлятор синхронизирует свои диагностические исходники в `BGXAI_DEV` (не в `override`), но сам живой ИИ не меняется. При любой ошибке остановить без повтора.

Причина проверки: в тестовой группе из шести персонажей Джахейра применила `Entangle` по больному гибберлингу, зона попала на союзников, Жаган позже успешно вылечил Тарану с 2/14 до 8/14 HP. **Лечение BGXP5 сохранено**. Здесь ищем только блоки источника массового контроля, не считаем по одному скриншоту, что это именно EPS, а не другой BCS.

Примечание: некоторые заклинания могут отображаться в BAF через числовые IDs; поэтому полный декомпилированный BAF включается в ZIP, а отсутствие строковых совпадений **не доказывает** отсутствие AOE. Это диагностическая программа, **не** готовый AI-модуль защиты от AOE.
