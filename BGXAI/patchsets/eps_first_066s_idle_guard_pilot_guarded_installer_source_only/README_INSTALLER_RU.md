# BGXAI — минимальный пробный установщик для действующей 066S

**Статус: SOURCE ONLY / НЕ УСТАНАВЛИВАТЬ БЕЗ ОТДЕЛЬНОГО РАЗРЕШЕНИЯ ПОЛЬЗОВАТЕЛЯ.** В пользовательской EET по-прежнему установлена исходная 066S с EPS 18.4. Ни один файл игры не изменён этой разработкой.

Цель — получить **один проверяемый результат в игре**, а не очередной номерной эксперимент: при двух F-включённых охранниках предпочесть возможного свободного защитника вместо ближайшего занятого автоатакой EPS. Правка только в двух участках точного `M_BX43.lua` действующей 066S; **`BDDEFAI.BCS` и EPS не изменяются.** Условия выдачи действия остаются в существующем BCS: F=ON, `ActionListEmpty()`, `ModalState(NONE)` и остальные проверки. При одном занятом охраннике улучшения НЕ ожидается. Состояние `m_curAction.m_actionID=0` — лишь подсказка, а не доказательство происхождения ручного приказа или пустой очереди EPS.

## Границы безопасности

- Проверка **точных SHA256** в игре: исходная Lua `50640902ec4c25a2c85e5088d7231678b54445a847b41743c476974236d1d70f`, BCS `fb435d82e6c3e0ebea1d6a9532753921bd5411d70ac0677dc1fd8ec483380476`. Новая Lua `2bf43c6ce4d607c13ce1aaf5a6af34810e0d4e81e2272c7a37dce384b6413e1a`.
- Установка только при последней записи `WeiDU.log` для BGX66S; наличие предыдущей версии и штатного WeiDU обязательно.
- Загрузка и установка не выполняются автоматически. Скрипт по умолчанию только читает статус. Любая запись в игру требует **одновременно** явного режима `install`, флага `--yes`, точной фразы-подтверждения и Windows с каталогом `C:\Games\BG_EET_FOXX_NEW`.
- Перед записью: проверка, что игра, InfinityLoader и WeiDU закрыты; внешняя копия исходных файлов с SHA-проверкой в `Documents\BGXAI_IDLE_GUARD_SAFE_BACKUPS`, повторный контроль `WeiDU.log`.
- Изменение файлов выполняет **WeiDU как отдельный компонент**, чья TP2 содержит лишь `COPY` для Lua. По окончании проверяются Lua и BCS, а также неизменность `chitin.key`, `weidu.conf`, `dialog.tlk`, `dialogf.tlk`. Любой сбой останавливает работу **без автоматического повторения**; резервная копия остаётся.
- Откат через WeiDU до **точной исходной 066S** имеет отдельную фразу подтверждения и собственный backup.

## Что реально проверено

- 15/15 проверок установщика в **синтетическом каталоге игры**. Включены обход иных последних WeiDU-компонентов, несовпадения SHA, отсутствие архивных файлов, совпадение backup, модельный цикл WeiDU-установка/откат, реакция на сбой и на изменения НЕцелевых файлов.
- 18/18 Lua тестов исходной 066S, 17/17 совместимости, 15/15 тестов предпочтения свободного охранника, синтаксис Lua 5.4 — PASS.
- Реальный запуск WeiDU, реальные процессы Windows, сохранения пользователя и поведение партии **не тестировались**. Модельный результат НЕ означает, что игровой эксперимент прошёл успешно.

## Следующие действия

Пока **ничего запускать не нужно**. После отдельного разрешения первым действием следует выполнить **только read-only preflight**; лишь если он пройдёт, разрешать экспериментальную установку, игру A/B и, при необходимости, откат. Никакой прямой подмены `override\M_BX43.lua` вручную.

В архиве `BGXAI_IDLE_GUARD_INSTALL_SOURCE_ONLY.py` — исходник защищённого установщика, `test_guarded_installer.py` — офлайн-тесты, исходник/кандидат Lua, `066S_idle_guard_minimal.diff`, тесты Lua и контрольные суммы. Это **не готовый автономный ИИ**: он проверяет один узкий тактический прирост, не меняя рабочие EPS функции.
