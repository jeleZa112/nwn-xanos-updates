# BGXAI — Priest Roles EPS-first, устанавливаемый игровой пилот (16.11.2026)

## Что сделано

После живых испытаний с жрецом Jagan Battleforge (EPS `bddefai`, F=ON) подтверждено: жрец при сближении применил Cure Light Wounds, на расстоянии мог стоять при 1/6 HP у Jade. Нельзя приписывать вину последнему BGXTEAM без контролируемого A/B; исходная 066S также имела жёсткий `Range(PlayerN,10)` и реагировала на подтверждённый hit. Ключевая новая задача — **дополнительный периодический отбор тяжелораненых и ограниченный подход без нового попадания**, сохраняя EPS18.4.

**Реальный новый код**: `BGXPR_LAST_PRIORITY.baf` (42 BAF блока — 24 лечения +18 ограниченных подходов), `M_BX43_066S_PRIEST_MODES.lua` и `M_BX43_BGXTEAM_PRIEST_MODES.lua` (сохраняют побайтно исходные Lua 066S/BGXTEAM, добавляют персональную клавишу Ctrl+Shift+J), `BGXPR_BCS_PATCH.py` (проверяет 1088 старых BCS блоков, строго добавляет 42 новых в **конец**, сохраняя все существующие), `BGXPR_INSTALL.py` (строгие SHA-проверки, game IDS WeiDU compile в temp, backup за пределами игры, требуемое отдельное текстовое подтверждение, статус, WeiDU откат на точную исходную базу).

Переключатель `BGXR_ROLE` — 0 OFF/EPS, 1 Лекарь (Heal<70%, Move<55%, max30), 2 Поддержка (Heal<45%, Move<35%, max25), 3 Боевой (Heal<25%, Move OFF), 4 Авто (Heal<45%, Move<35%, max20). Переключение только у жреца-союзника в слотах 2–6 с уже известным CLASS.IDS жреца/комбинированного жреца. F `BGX38_GUARD=1` остаётся независимым обязательным условием. Реально запомненное Cure Light Wounds, `ActionListEmpty`, `ModalState(NONE)`, видимость, те же ARE, близость, своё здоровье, cooldown и блокировка при pending BGX66 healing обязательны. Никаких Lua `Attack/Spell/Move` действий; EPS раньше по порядку BCS, новый модуль — только last-priority fallback. Прямой путь в опасную зону *не доказан безопасным*: ограниченная дистанция/порог здоровья/противник в радиусе 8 — лишь сниженный риск.
