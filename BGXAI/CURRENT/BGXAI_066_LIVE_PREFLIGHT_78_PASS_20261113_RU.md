# BGXAI 066 — пользовательский preflight 78 PASS; релиз пока не устанавливать без фронтовика

Дата: 2026-11-13. Последний живой результат с Windows 10, EET 2.6.6.0 + SCS 35.21 + EEex, Insane.

## Подтверждённые факты
- Активный BGXAI_UPDATE.cmd проверил pin 33916f4ff3a2 (SHA256 OK; GitHub REST не использовал).
- Пункт 78 скачал и проверил 14 исходников 066 в BGXAI_DEV, не изменив игру.
- `proof.status`: `INSTALLED_064_VERIFIED`; последняя WeiDU запись: `~BGX64\SETUP-BGX64.TP2~ #0 #0`.
- BCS SHA256: `db0fcba4678b00defa2ed7887b57c0d4207effc064891aeb9a0d7dcc1a1a6b0b`.
- Lua 064 SHA256: `bfee5278b5b69b1fb4a02e3fea321082b0238407789df83ec6bd2f78d7e19f4b`.
- Скомпилированный исходный кандидат 066 SHA256: `c66ebb5190be8103819106a48d3100055b5791adf7c2d1df5f3e54596823540b`.
- Вывод: `BGXAI066 preflight PASS. Game remains 064 until separately authorized installation.` Приглашение к установке не выполнялось (`authorized_to_install=false`). Игровой runtime 066 не проверялся.

## Важный регрессионный риск на текущем составе
Последняя native EEex проверка: P0 fighter (slot 0, не рассматривается охранником в 066), P1 mage F=ON, P2 bard F=OFF, P3 cleric F=ON, P4/P5 отсутствуют. Текущий код 066 допускает активные BCS-запросы лишь персонажам класса 2 (fighter), 6 (paladin) или 12 (ranger) в слотах 1..5 при F=ON, HP>50%, same area и свободном модальном действии; для магов/жрецов команда не выдается. Таким образом с этим составом **возможна потеря проверенного поведения 064** у кастеров и **ноль** активных заявок 066. Нельзя рекомендовать немедленно устанавливать 066 как улучшение ИИ текущей партии. Вместо этого либо нужен подходящий спутник-фронтовик с F=ON для реального теста версии 066, либо переработка role-capability поддержки кастеров без принудительного ближнего боя.

## Следующий практический шаг
- Не повторять preflight 78, проверки BGX64/65 или загрузку 45к EET ресурсов.
- Сохранить 064 установленной до решения задачи совместимости ролей; развивать безопасное управление магом/целителем либо планировать игровой тест с фронтовиком.
- Пункт 79 действительно позволяет установить 066 после отдельного ввода `INSTALL_BGXAI_066`, с предустановочной проверкой, резервной копией и возвратом 81 к 064. Не считать установку фактом без отчёта `INSTALLED_066_VERIFIED` и read-only статуса 80. Даже успешная установка не доказывает боевую работу.
