## 4. Реальные причины технических остановок — сохранить, чтобы не наступить повторно

- Прежние BCS-патчи ломались на **LF/CRLF/SC-footer**. Только native parsing, точный сохранённый block count + sha; не делать слепых regex-replace по BCS.
- WeiDU 25100 в реальной игре расположен как `setup-enhanced-powergaming-scripts.exe`, а не обязательно `weidu.exe`. Нужен точный SHA-пин и проверка пути; не требовать заведомо отсутствующий файл.
- Неправильные ожидания R29: «RANGED7 installed last» и «RANGED7 installed at all» при реальном V6; два ложных STOP. Вспоминать реально установленную lineage прежде чем строить новый preflight.
- GitHub `CODE` и `CI PASS` не означают `GAME DEPLOY/LIVE`; 53/53, 439/439 x Lua и сотни synthetic combos только регрессия. Некоторые **исторические GitHub Actions** красные из-за устаревшего immutable pin и старых размеров; не говорить «все CI зелёные», оценивать конкретный run и компонент.

## 5. Обязательный план дальнейшей работы: единственный P0

**P0 — интеллектуальный выбор лучшего оружия. Не переключаться на сторонние ветки до LIVE результата, если нет угрозы сохранности.**

2. **Queue and authority:** доказать, что текущий приказ не ручной и не активное EPS лечение/магия/песня/атака; protected cooldown, actor↔target identity, очередь без лишнего Stop/ClearActions. Advisory NONINTERRUPT сохраняет план, а не обрывает действие. Не позволять внешнему скрипту ставить `BGXW3_REQ` без независимого валидатора.
3. **Closed-loop composer:** соединить реальные snapshots → **уже написанные** V5→V4→V3→NONINTERRUPT → защищённый producer → **уже скомпилированный** `SelectWeaponAbility` BAF consumer. При любом сомнении — оставить текущее оружие, не преследовать друзей, не спамить новые команды.
4. **Verification:** негативные сценарии (ручной приказ, лекарь, баф, F=OFF, mageless, отсутствие ammo, сопротивление, обрыв дистанции, berserk/friendly fire, speed/APR/haste) + native WeiDU/EEex + SHA, затем отдельное typed approval и обратимая установка через прежний CMD. 5. **LIVE A/B:** на отдельном сейве реальные альтернативы (меч/лук/дротики/праща), APR от специализаций/временных бафов и effects, отсутствие простоя/срыва каста, отсутствие friendly атаки, влияние вражеских защит. Статус «работает» только при точном игровом наблюдении и отсутствии регрессий.

**Критерий успеха:** хотя бы один персонаж в реальном бою выбирает **лучшее** оружие из двух актуальных альтернатив при изменённых бафах/дистанции/противнике, и решение доказанно зависит от реальных свойств альтернатив, не просто от фиксированного правила bow→sword. После достижения P0 продолжить ранее выбранные роли/магию/бардов/безопасные AoE и тактическое взаимодействие.
