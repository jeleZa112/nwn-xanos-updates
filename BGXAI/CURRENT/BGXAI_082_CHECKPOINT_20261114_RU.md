# BGXAI 082 — связка 080 + 081 с запретом неизвестной очереди EPS

**Дата:** 14.11.2026. **Статус:** SOURCE ONLY / OFFLINE PASS; НЕ УСТАНОВЛЕНО. В установленной EET 066S, EPS 18.4, EEex 1.1.7, SCS 35.21; без изменения BCS, Lua, WeiDU, обновлятора, F-охраны и игры.

**Повод:** после 080 пользователь потребовал продолжить: проверить реальное наличие API очереди и происхождения команды, чтобы не повредить автобафы/лечение EPS. В 081 был проверен точный SHA Lua 066S, старый наблюдатель сам указывает `origin_verifiable=false`, `queue_verifiable=false`, `P.manualOriginKnown=false`. EEex событие начала действия и `m_curAction.m_actionID` не доказывают пустоту EPS-очереди или источник команды. 081 не выдаёт боевых приказов, 289 Lua + 13 Python PASS; SHA-манифест 7/7 PASS. Исходник 066S сохранён отдельно в закрытой библиотеке и не публиковался в пакете.

**082 реализован:** новая чистая `BGXAI082_QUEUE_GUARD_BRIDGE.lua` соединяет 081 (наблюдения ID действия) с 080 (координатор лечения/охраны) и принудительно делает `action_state` непроверенным, даже если внешний ввод ошибочно заявляет `verified=true, origin_verified=true, queue_empty=true, current_action='IDLE'`. Любая попытка выдать из этого реальные рекомендации — fail closed, `HOLD_NO_ENGINE_DISPATCH`. Нет EEex hooks, engine calls, изменённых предметов/эффектов, BCS запросов, записей LOCALS. Не использует списки бафов, а сохраняет занятость любого действия EPS.

**Проверки:** `texlua test_082.lua` = **765/765 PASS**; `python -m unittest -v test_082.py` = **14/14 PASS**. `python verify_release_082.py` = **9/9 SHA PASS** + статический NO_GAME_WRITE PASS. Синтетические входы (49 сочетаний ID, неизвестные действия, ложные 'всё свободно') — не реальная EEex-сессия. **ZIP SHA256:** `384228584b07bff52f18fcb8eab9e78318a23392ff7e664bb72b4007bb1ecfc7` (14255 байт).

**Реально установлено:** BGXAI 066S. Все 067–082 только исходники/hold. Живого API проверки происхождения и очереди на EET не доказано. Следующий шаг, если нужен игровой апгрейд: строго ограниченный диагностический runtime adapter (пассивный, opt-in, отдельно одобренный) после проверки его влияния на игру. Не устанавливать 080–082 как моды. Офлайн-код не заменить доказательством реальной активности EPS.
