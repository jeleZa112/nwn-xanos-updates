## Реально найденная ошибка в SOURCE ONLY V2 и исправление

Прежний файл `BGXAI_EEEX117_WEAPON_RUNTIME_EVIDENCE_V2.lua` жёстко ограничивал `m_id` диапазоном `0..65535`, поэтому для настоящего объекта `139135050` выдавал `HOLD_SELECTED_WEAPON_OR_ID_UNAVAILABLE` и не позволял сравнить до/после. Исправлены **только проверки actorId** на `0..2147483647`; 16-битные поля `selectedWeapon`, `actionId`, `scriptNumber` не расширяли. Добавлены тесты на реальный actorId, переход 12→35, исключение `2147483648`; всего **18/18 Lua PASS (offline)** вместо прежних 15/15. Для полного журнала разработан отдельный неисполняемый Python-аудитор с **12/12 PASS**, который проверяет ограничения наблюдателя и не разрешает игровую диспетчеризацию.
