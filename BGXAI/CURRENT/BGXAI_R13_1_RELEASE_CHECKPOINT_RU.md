## Следующий шаг для пользователя

Установка является изменением игровой установки. Требуется отдельное явное согласие пользователя. После согласия: закрыть BG/InfinityLoader; запустить **существующий** `C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd`; главное меню `161`; внутреннее меню `3`; при точном запросе набрать `INSTALL_BGXAI_R13_PASSIVE_TARGET` и Enter. Результат `BGXTD13_INSTALLED_AWAITING_LIVE_TEST` означает установлено, но ещё не проверено в игре. Сразу прислать полный JSON. Отсутствие согласия — не устанавливать; нельзя выдавать `161 → 2` за разрешение.

После установки: отдельный короткий тест R13 LIVE в игре для чтения защиты цели; не включать автопереключение, не повторять старые тесты R1-R4 и пункты 158/159/160. По положительным безопасным результатам продолжать без дополнительных `+` в рамках активного обращения.
