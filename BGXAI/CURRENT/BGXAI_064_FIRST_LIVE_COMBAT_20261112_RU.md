# BGXAI 064 — первый живой боевой тест, частичный отклик, не финальный PASS (2026-11-12)

Пользователь прислал скриншот EET v2.6.6.0 в помещении, бой с Шанком. Боевой журнал: `Шанк: бросок атаки 13 + 0 = 13 : попадание`, `Jade: получает 1 колющего урона от противника: Шанк`, затем **ПАУЗА**. По наблюдению пользователя: «на аттаку на таком среагировал только 1 спутник второй сделал баф но стоит в тот раз он нормально отрегировал».

Вывод: реальная атака подтверждена, один спутник явно отреагировал, другой применил баф, но стоял в момент паузы. **Это НЕ доказательство отказа или PASS 064**; нет диагностического выбранного ID или BCS branch/REQ, и первый кадр был на паузе.

Проверка точного опубликованного Lua `experimental_064_guarded_weidu_source_only/M_BX43_064_CANDIDATE.lua`:
- `BGX52Bridge.prepare` фильтрует кандидатов F=1, modal=0, sameARE через `EEex_UDEqual`, сортирует по квадрату расстояния до жертвы, tie-breaker portrait slot, выбирает только `options[1]`; пишет BCS запрос `BGX52_REQ_SLOT` только выбранному. **Одна ответная охрана на один подтверждённый удар — это архитектура текущего 061/064, два не обязаны оба атаковать.**
- Сверенный исходник `BGX61_RECEIVER.baf` требует `ActionListEmpty()`, `ModalState(NONE)`, cooldown, в ветке реталиации требует 10 футов, для подхода 10–40 футов и одну ARE. Баф EPS может временно держать очередь действий занятой.
- BCS/WeiDU status 75 уже PASS; не повторять 74/75 и не откатывать без причины.

Следующий БЕЗОПАСНЫЙ тест при желании: продолжить с паузы несколько секунд, посмотреть какое действие выполнит спутник, и прямо в игровой Lua-консоли прочитать счётчики `BGX43Probe.snapshot()` — `weapon_hit_calls`, `bridge_prepared_count`, `bridge_attempts`, `bridge_last` (`chosen_guardian` или `reason`). Не запускать в Windows PowerShell; только чтение, без изменения игры. Не трактовать `bridge_last` как историю всех ударов, это лишь последний результат.

Если пользователь ожидает, что оба охранника атакуют, это отдельная будущая функция координации нескольких защитников; изменение 064 само по себе только добавляет same-area фильтр к одиночному селектору. Рабочую установленную 064 пока сохранять до диагностики.
