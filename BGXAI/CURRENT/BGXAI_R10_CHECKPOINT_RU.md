# BGXAI — R10: интервальная оценка физического урона + аудит реальной R3/R4-матрицы

Дата: 22.11.2026. Вход: R9 `BGXAI_WEAPON_R9_CONTEXT_LEDGER_V1`, текущая ветка проектирования R6→R9. **Без изменения игры.**

## Сделано (CODE)

- `BGXAI_WEAPON_R10_INTERVAL_RANKER.lua`: чистая Lua-модель осторожных интервалов **некритического физического урона/раунд**, без команд, без EEex, без установки. Для каждого занятого quickslot 35–38 получает диапазоны APR, THAC0, AC цели, урона до эффектов, доли проходящего урона и возможности контакта, обязательно связанные с одним снимком и действующими отпечатками персонажа/экипировки/бафов/цели. Нельзя переносить APR R9 на другие слоты. Неизвестная устойчивость/защита/дальность выражается `[0,1]`, а не по умолчанию `1`.
- Математика попадания для обычного d20: естественная 1 — промах, 20 — попадание; `p = clamp(число бросков 2..19 + 1, 1, 19)/20` при пороге `THAC0−AC`. Проверено по официальному руководству BG: https://files.beamdog.com/files/BGIIEE-MasteringMeleeandMagic_en.pdf (обычная модель; игровые модификаторы/особые атаки требуют отдельного учёта).
- Возможная строгая доминантность определяется **только внутри модели** (`min(candidate)>max(all others)`), но **никогда** не даёт права на переключение. Криты, магия, яды, спецэффекты, иммунитеты и очередь EPS/manual явно исключены из полномочий модели.
- `BGXAI_R10_EVIDENCE_AUDIT_RO.py`: проверка ранее сохранённой *реальной* матрицы `BGXAI_WEAPON_R4_R3_EVIDENCE_MATRIX_20261122.json` с защитой от приписывания native APR и игнорирования статусов HOLD. Она сохраняет 16/16 согласованных событий R1/R2/R4 и три исторических значения APR, **не делает прогноз точного DPS цели**.
