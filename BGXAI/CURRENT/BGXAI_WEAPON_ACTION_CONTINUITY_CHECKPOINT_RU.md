# BGXAI — непрерывность действий при пересчёте выбора оружия (21.11.2026)

## Требование пользователя и изменение поведения

Временное ускорение, изменение силы, окончание бафа или смена противника **не должны приостанавливать существующую атаку, каст, лечение EPS либо ручной приказ**. Сбрасывается только внутренняя *оценка оружия*, а не действие движка и не его очередь. Выбор наилучшего оружия и фактический приказ переключить слот — две разные операции.

### CODE

1. Обновлён `BGXAI_WEAPON_PRIORITY_LUA_V3.lua`: сохранён старый `M.choose` с полным запретом рекомендаций при ручном приказе/EPS/касте; дополнительно добавлен `M.preview`. Он **обходит эти ограничения только для пассивного сравнения** оружия по достоверным данным; не ослабляет проверки эффекта, APR, защиты цели, снарядов, слотов, класса, области. При потенциальной выгоде возвращает специальный статус `PASSIVE_RANKING_SUGGESTS_SLOT`, а не обычную рекомендацию для исполнительного контура. Всегда `executable=false` и `dispatchAuthorized=false`.
2. Новый `BGXAI_WEAPON_NONINTERRUPT_PLAN_V1.lua` — чистый Lua-планировщик. Вызывает только пассивную оценку, не посылает команды игре. Поддерживает рекомендацию в памяти, пока завершится текущая атака/каст; не требует оставлять персонажа без действия ради пересчёта. Если fingerprint бафов, активных характеристик, цели, предметов или защиты меняется, отклоняет старую рекомендацию и пересчитывает с новой ситуацией. В ожидании безопасного момента **не ставит персонажа в простое и не выполняет Stop/ClearActions/Attack/SelectWeaponAbility/SetGlobal**.
3. Старые V4 (сила, яд, праща), V5 (APR, владение) и `BGXAI_WEAPON_CURRENT_STATS_BRIDGE.lua` сохранены. Для цепочки фоновой оценки используется только `currentStatsBridge.choose(scene, previous, v4.choose, v3.preview)`; нельзя подменять реальные ручные флаги ложным `false`.
4. Планировщик намеренно возвращает *только совет*, даже если офлайн-модель дала признак «безопасная граница действия». `m_actionID=0` не подтверждает пустую очередь, источник ручного приказа и свободу EPS.
