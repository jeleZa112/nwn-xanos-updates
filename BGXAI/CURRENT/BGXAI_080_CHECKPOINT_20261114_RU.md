## Созданное улучшение архитектуры

`BGXAI080_EPS_FIRST_COORDINATOR.lua` — без игровых вызовов, связывает 078 (селектор действительно пригодного лекаря, автоматический следующий кандидат) и 072 (точная цель охраны с известным реальным нападавшим), но **никаких боевых приказов не отправляет**. По умолчанию opt-in off. При подтверждённых сведениях о разных свободных персонажах может предложить одновременно лечение и охрану, если не нарушается приоритет лечения; при HP ниже 25% охрана уступает экстренному спасению. Никакого вручную написанного списка бафов: **любой** начатый/неизвестный action или неподтверждённая очередь/происхождение команды -> HOLD, manual/cast/song/traps/heal -> HOLD. Fail-closed на неподтверждённых данных, повторных ID, ошибках модуля или нечестном результате внешнего селектора. Входные снимки не мутируются.

Непроверенный `action_state.verified=true`, `eps.verified`, `origin_verified`, `queue_empty` **не могут быть получены произвольно из текущего 066S**. Его `BGX43Probe.manualOriginKnown=false`, `queue_verifiable=false`. Это стоп для внедрения, а не разрешение игнорировать данные.

Результаты: **82/82 нативных теста Lua PASS, 16/16 Python PASS на настоящем историческом 041 BCS**, release **8/8 SHA256 PASS** + no-write gate PASS.
