Пользователь предпочитает короткую конкретную обратную связь, а не десятки повторных игровых тестов. Все важные наработки, тесты, сбои, решения, код и версии сохранять в GitHub сразу, до завершения чата.

## Рабочий цикл до «идеала» — обязательный
1. **Игрок играет**, локальная read-only телеметрия фиксирует только наблюдаемые события и изменения параметров; при желании игрок присылает лог + скриншот. До live-bridge это не автоматическое наблюдение из текущего чата.
2. **Анализ:** краткий отчёт «что произошло / что сломалось / почему / какое действие выгоднее / уверенность». Не повторять вопросы и тесты, на которые уже есть ответ. Использовать реальные игровые логи, сверять скрипты и источник SCS.
3. **Решение:** минимально достаточная корректировка правил или планировщика, предварительно офлайн replay прежних логов и регрессии, проверка доступных SPL/ITM и EEex API.
4. **Релиз:** отдельная версия/коммит, резервная копия, проверка BAF→BCS→активных алиасов, команда отката. Не выдавать прохождение JS-тестов за компиляцию WeiDU и реальную игру.
5. **Контроль:** один репрезентативный игровой тест, если возможно; новая телеметрия. Если плохой результат, откат, а не ещё десяток сломанных hotfix.
6. **Сохранение:** после каждого важного испытания/вывода/фикса обновить данный HANDOFF и журнал изменений, чтобы новый чат начинал с реального текущего состояния. В GitHub по возможности коммитить перед значительным переключением темы.

## 2026-11-03 — жёсткое ограничение стоимости BGXAI Live Bridge
Пользователь использует ChatGPT Plus и **не может оплачивать более дорогой тариф или дополнительный платный API**. **Рабочий режим по умолчанию полностью локальный, без платных API и подписок**. Не включать OpenAI API/сторонний платный сервис без отдельного явного согласия и предупреждения о цене.
- Сбор/фильтрация BGXAI_COMBAT.log на ПК: read-only наблюдение, локальный буфер, компактные инциденты/сводки, ограниченная длина. Не передавать все action events в ChatGPT и не заполнять контекст многомегабайтными логами.
- Пользователь вручную прикрепляет отобранный отчёт при необходимости; ассистент анализирует и сохраняет код/решения/результаты в GitHub.
- Github ledger/handoff являются долговременной технической памятью проекта, отдельно от ограниченного контекста чата и ChatGPT Memory; GitHub не расходует «память ChatGPT», но запросы в чате подчиняются лимитам тарифа.
- Live-LLM анализ в режиме реального времени пока **недоступен без внешнего подключения/оплаты**, не выдавать локальную детекцию событий за работу GPT в реальном времени. Базовый мост логов сам по себе остаётся бесплатным.

## 2026-11-03 — LIVE 0.3.1: первый Windows запуск и устранение кодировки
