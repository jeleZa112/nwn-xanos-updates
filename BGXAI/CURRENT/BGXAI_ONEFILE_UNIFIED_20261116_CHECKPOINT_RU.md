## Новые пункты единственного BGXAI_UPDATE.cmd

97 — **BGXPR status**: только проверка уже установленного мода, автозагрузка/сверка исходников. При успешной проверке должен вывести `READ_ONLY_STATUS` и `BGXPR_INSTALLED_VERIFIED`.

98 — BGXPR read-only preflight; если уже установлен, не компилирует/переустанавливает, а выводит текущий статус.

99 — BGXPR install (только если отсутствует, с отдельной фразой `INSTALL_BGXPRIEST_MODES`, SHA, игрой закрытой, внешним бэкапом и WeiDU).

100 — BGXPR rollback (только если BGXPR последний WeiDU, фраза `ROLLBACK_BGXPRIEST_MODES`, внешняя проверенная копия).

101 — BGXTEAM status. Если поверх стоит BGXPR, показывает, что BGXTEAM ниже, и предлагает сначала пункт 97.

102 — BGXTEAM read-only preflight.

103 — BGXTEAM install (фраза `INSTALL_BGXAI_TEAM_GUARD`, только если допустимая прежняя база 066S).

104 — BGXTEAM rollback (фраза `ROLLBACK_BGXAI_TEAM_GUARD`, только если BGXTEAM последний мод; при BGXPR поверх блокируется).

**Пункт 94 по-прежнему управляет старым BGXIDLE, а не BGXPR/BGXTEAM.**
