## Новый результат R4 — CODE и TEST (не LIVE)

Разработан пассивный модуль `M_BGXW4.lua` (9843 байта, SHA256 `0d24779ee6cf7071c611c3b3d509ddb71f97e18eb95a6c5839e1a8441ee3f3e8`). Он использует EEex started-action listener, принимает только члена партии, не больше 64 записей за запуск, выдаёт `BGXAI_WEAPON_ACTIVE_R4` в direct JSONL или консоль. Считывает **29 полей** `CDerivedStatsTemplate` из EEex x64, включая APR, THAC0, уровни1/2/3, kit, силу и ловкость, melee/missile bonus, haste и **RAW** прокачку LongSword/ShortBow/QuarterStaff, combat styles. Читает только текущее выбранное оружие. Не устанавливает классы/киты по догадкам, не считает поля пипсами без аудита, не утверждает полный снимок всех бафов или очередь EPS. Вызовов переключения и других игровых действий нет.

Чистый Lua `BGXAI_WEAPON_ACTIVE_R4_READONLY.lua` умеет сравнивать последовательные необработанные срезы; при изменении APR, STR, haste, владения или выбранного слота возвращает **`INVALIDATE_CACHED_WEAPON_ADVICE_KEEP_ACTION`**, а не игровой приказ. При неизменных полях не объявляет все активные эффекты проверенными: `allBuffsObserved=false`, `alternateSlotAPRVerified=false`, `dispatchAuthorized=false`.

Сохранён старый приоритетный код V3/V4/V5 и `BGXAI_WEAPON_NONINTERRUPT_PLAN_V1.lua`; параллельный переключатель **НЕ** создавался.

Тесты **R4: 20/20 чистый Lua + 10/10 EEex hook mock + 28/28 Python guarded install/collector mock = 58/58 OFFLINE PASS.** Дополнительно **старые** тесты неперерывания 22/22, native priority V3 24/24 и совместной работы V3/V4/V5 3/3 PASS. Эти PASS не означают Windows WeiDU/EEex LIVE R4.

В `BGXW2_OBSERVER_GUARDED.py` добавлены только опциональные пункты R4 в прежнее вложенное меню; оригинальные R1/R2/R3 пункты оставлены, защищённые установки требуют закрытой игры, точной SHA, SHA-бэкапа вне каталога игры, WeiDU-last-only rollback и явного отдельного пароля `INSTALL_BGXW4_READONLY_ACTIVE`. Консольный сборщик R4 различает direct/log, проверяет 29 полей, 64 seq, статус, проверяет отсутствие разрешения на игровые действия, отклоняет конфликты, выбирает последний полноценный сеанс.
