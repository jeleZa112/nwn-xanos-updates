# BGXUNI 0.1.2 — обход ошибочного запуска старого CMD

Дата: 03.11.2026. Реальный скриншот пользователя повторно показывает `setup-BGXUNI.exe: unknown option '--tp2'`, что однозначно соответствует прежнему `BGXUNI_SETUP.cmd` версии 0.1.0. На экране нет нового баннера 0.1.1, поэтому ошибка установки 0.1.1 не доказана: запущен старый файл (либо старое окно, либо другая копия CMD).

## Новый отдельный файл

`BGXUNI_RUN_012.cmd` (SHA256 `023361af9d7c6daf5ecaca0c8c5f847abb23e958d446b607066af2c4ec40dacf`) НЕ заменяет и не вызывает старый `BGXUNI_SETUP.cmd`. Запустить его можно из Загрузок: он проверяет `chitin.key` рядом с собой, а при отсутствии ищет ранее подтверждённый пользователем путь `C:\Games\Baldur's Gate Trilogy (EE)`. При другом расположении игры нужно скопировать единственный файл в её корень. Устанавливаемая папка `BGXUNI` уже существует после предыдущей распаковки. Если не существует — прекращаем без установки.

Новая первая строка окна: `BGXUNI RUN 012 - NEW LAUNCHER - WEIDU 251 - NO UNSUPPORTED --tp2`. Подчеркнуть: `--tp2` упоминается только в информационном тексте; вызов выполняется **`setup-BGXUNI.exe --yes`**, с `setup-BGXUNI.tp2` в корне. Команда `--yes` подтверждена upstream WeiDU 251. Проверка расхождения root TP2 запрещает перезапись отличающегося файла. Скрипт не меняет `BDDEFAI`, `BGXGRP`, `BGXTANK`, BGXAI_UPDATE/LIVE или NWN.

## Проверка пользователем

1. Завершить старое окно (`Ctrl+C`), закрыть игру и InfinityLoader.
2. Скачать и извлечь единственный новый `BGXUNI_RUN_012.cmd` из ZIP. Выполнить **именно его** двойным щелчком. Если окно не показывает `BGXUNI RUN 012`, открыт старый ярлык/файл.
3. При успешном preflight нажать любую клавишу. Вывод должен дойти до `Executing: setup-BGXUNI.exe --yes` и затем `SUCCESS ... scripts\BGXUN1.BS exists` (если пройдёт настоящая WeiDU-компиляция).
4. Если новая ошибка — предоставить скрин `BGXUNI 012` и при необходимости новый `setup-BGXUNI.DEBUG`. Не присылать старые 45k ресурсов/WeiDU.log/архивы заново.
5. После успеха назначить BGXUN1 только одному NPC, остальных не менять.

Офлайн проверка уникального CMD: обязательные входные файлы, отсутствие запуска `--tp2`, явный отдельный banner, проверка названия 8-char resource, SHA256/ZIP CRC PASS. **Компиляция в реальном пользовательском WeiDU 251 и тест в игре всё ещё НЕ подтверждены.**
