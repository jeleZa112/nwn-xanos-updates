# BGXAI 042A — безопасный исходный прототип (НЕ УСТАНОВЩИК)

**В игре ничего не менялось.** Патч предназначен для офлайн-анализа и подготовки последующей проверяемой установки через существующий `BGXAI_UPDATE.cmd`, а не для ручного копирования в `override`.

Проверен сохранённый исходный `BDDEFAI.BCS` EPS 18.4 + BGXAI 041: SHA256 `86d80953be464a3f10da8e1dc031b907801860b7f1f15b3ea6fb9d25e485f3f5`, 2 229 760 байт, 1057 блоков. В **предпросмотре** 11 байт-в-байт неизменённых `ProtectObject` перемещены с позиций 1047–1057 на 1032–1042, перед обычной атакой EPS (новые позиции 1043 и 1056). Структура всего BCS, остальные действия/триггеры и байты каждого блока сохранены. Порядок остальных 1046 блоков не изменён.

## Эффект и ограничение

Модель ожидает: если в момент освободившейся очереди защита активна и для неё выполнены штатные условия угрозы, `ProtectObject` успеет выполниться прежде нового `Attack`. Сам механизм охраны сохраняется; F/значок 041 и все заклинания предшествующих блоков остаются на прежних местах.

**Это не универсальный работающий боевой патч.** Команда `Attack()` по IESDP является продолжительной и не освобождает очередь до завершения текущей цели; **только перестановка не прервёт уже исполняемую атаку**, не перенаправит занятый в бою охранник мгновенно. Нет реальной проверки WeiDU/игры, моделей теста 26/26 не достаточно для заявления о функциональности. Более сложная предвыборка ручного/скриптового Attack требует EEex runtime-телеметрии либо отдельного доказанного триггера и явного согласования поведения.

## Границы безопасности

- Скрипт `build_042_preview.py` **не** обращается к `override`, не устанавливает мод, не запускает игру, не пишет в WeiDU.log и без `--preview` вообще ничего не пишет. Запись `--preview` отказывается от пути с компонентом `override` и от исходного файла. Дважды проверяется SHA256, полный подсчёт блоков, сохранность каждого байта условий и действий.
- Нельзя вручную подменять оригинальный BCS готовым preview: текущая работающая 041 защищена. Для установки требуется отдельный WeiDU компонент с безопасной операцией COPY_EXISTING/backup, строгий SHA256 до записи, запуск без открытой игры и надёжный откат; политика выпуска пока не удовлетворена.
- Для опубликования в публичный GitHub **не** загружается пользовательский 2.2 МБ BCS или его модифицированная копия. Исходный BCS хранится только в приватной Library ChatGPT и в Windows игре.
