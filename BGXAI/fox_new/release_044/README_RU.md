# BGXAI 044 — безопасная диагностика установленного 043-P

Это **отдельный диагностический модуль**, НЕ новая боевая версия. 043-P уже установлен, а 042B остаётся рабочей охраной. 044 не меняет BCS, TLS/диалоги, UI.MENU, заклинания, музыку, русские строки, 043-P и скрипты EPS.

После защищённой установки 044 через единственный BGXAI_UPDATE.cmd и нового запуска игры через InfinityLoader.exe нажать **Ctrl+Alt+F11** (английская клавиатура не обязательна). Должна появиться экранная строка `BGX44: 043P loaded=... listener=... enabled=... attacks=... errors=... notice=... API=... last=...`.

- `043P loaded=true, listener=true` = 043-P фактически загрузился и зарегистрировал слушатель; если `attacks=0`, пока нет совпавших событий либо событие не было распознано.
- `loaded=false` = глобальная переменная 043-P отсутствует на момент нажатия.
- `listener=false` = 043-P существует, но не установил обработчик.
- `attacks>0` = зарегистрированы события атаки конкретного action ID на членов отряда.
- `errors>0` = ошибки чтения события (смотреть `last`).

044 не требует повторного боя с Шанком. Никакие боевые приказы 044 не выдаёт. При отсутствии сообщения даже по Ctrl+Alt+F11 возможна проблема загрузки самого 044/горячих клавиш/DisplayString; не делать вывод о 043-P только по отсутствию текста.

Запуск только через **C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd** (когда меню 23–27 опубликовано и локальный CMD уже обновлён). Сначала пункт 23 (read-only preflight), затем 25 (установка, YES, закрыть игру), после успешной установки пункт 26 (status). Пункт 27 — отдельный штатный WeiDU rollback, только если 044 последний, с подтверждением YES. Пункты 20/22 для старого 043-P не трогать.

Полностью локальный standalone запуск при необходимости:
`py -3 BGXAI_DEV\experimental_044\BGXAI44_INSTALL.py --status`

При BLOCKED/REVIEW сохранять вывод и остановиться, не повторять автоматически. Обязательный защищённый backup: `%USERPROFILE%\Documents\BGXAI44_SAFE_BACKUPS`. Только установленный через WeiDU диагностический Lua-файл `override\M_BGX44Diag.lua` удаляется при откате; ручного удаления файлов из игры не требуется.

Ограничения: тесты установщика на моковом WeiDU и Lua в системном Lua 5.4, НЕ Windows WeiDU/EEex LuaJIT в игре. Работоспособность отображения подтверждается только после живой диагностики.
