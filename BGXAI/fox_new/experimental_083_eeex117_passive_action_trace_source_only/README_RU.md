## Что добавляет 083

`BGXAI083_PASSIVE_TRACE.lua`: источник для будущего узкого read-only runtime adapter. При **вызове извне** читает `m_curAction.m_actionID` / необязательный `m_curScriptNum`, хранит последние <=256 наблюдений только в памяти, с безопасной обработкой недоступных полей. Никаких EEex hooks автоматически не регистрирует, не пишет LOCALS, не выдаёт действий, не редактирует игру; любой снимок маркирует queue/provenance как `UNKNOWN`.

`state:for_082()` адаптирует наблюдения к уже имеющемуся **082**. Даже когда внешний актор содержит поддельное `action_state.verified=true, queue_empty=true`, 082 остаётся `HOLD_NO_ENGINE_DISPATCH`.
