# BGXAI 084 — нативная проверка ActionListEmpty через EEex 1.1.7

**SOURCE ONLY. Не установлено. Игру и EPS не меняет.** Последняя подтверждённая установка 066S: BCS SHA256 `fb435d82e6c3e0ebea1d6a9532753921bd5411d70ac0677dc1fd8ec483380476`.

## Подтверждено по исходникам

У EEex v1.1.7 есть `EEex_Trigger_EvalConditionalStringAsAIBase(string, aiBase)`: `EEex_Trigger.lua` парсит строку условного триггера и вызывает `m_curCondition:Hold(aiBase.m_pendingTriggers, aiBase)`. Git blob `80da96ed5dc7cbcaa726631a3542ecafa533ec6f`; источник: https://github.com/Bubb13/EEex/blob/v1.1.7/EEex/copy/EEex_scripts/EEex_Trigger.lua . Базовый IE-триггер `ActionListEmpty()` = `0x402B` проверяет, что у **текущего существа** отсутствуют ожидающие действия. IESDP: https://gibberlings3.github.io/iesdp/scripting/triggers/bgeetriggers.htm . В `066S` BAF этот триггер уже используется перед шестью лечащими заклинаниями и одним `Shield`. Blob `f5e72c5c87d2dfefa4859bd2d7bbcd0110bdeddb`.

## Сделано

`BGXAI084_NATIVE_QUEUE_PROBE.lua` — автономный модуль без регистрации хуков. `sample(sprite, evaluator)` получает один булев результат `ActionListEmpty()` через явно поданный evaluator, отказывает при ошибках, плохом ID, не булевом ответе. `sample_from_eeex(sprite)` — **не вызываемый автоматически** кандидат для будущей верифицированной EEex-среды. Факт `queue_empty_sample=true/false` всегда остаётся лишь моментальным наблюдением, не подтверждением происхождения ручного приказа и не разрешением на dispatch. Интерфейс `for_082()` всегда отдаёт `queue_empty=nil`, `queue_empty_verified=false` и заблокированный статус для неизменного 082.

## Что НЕ доказано

Нет проверки на реальной EEex 1.1.7 пользователя: неизвестно, успешно ли парсится именно эта строка, не меняет ли `Hold` состояние `m_pendingTriggers` и как работает между тиками. `ActionListEmpty()` отражает состояние в момент проверки; не означает, что в следующем кадре EPS не поставит действие. Классифицировать команды как ручные по `m_curScriptNum` или action ID недопустимо. Установка, hook, отправка приказов, инсталлятор, изменение `override`, Lua/BCS/WeiDU/EPS **отсутствуют**.
