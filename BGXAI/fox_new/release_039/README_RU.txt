BGXAI 0.3.9 — дополнительная командная охрана для EET + EPS 18.4 + BGX38
СТАТУС: исходный код и локальные офлайн-тесты. Windows WeiDU и реальный бой 039 ЕЩЁ НЕ ПРОВЕРЕНЫ.

СЕЙЧАС установлена и подтверждена играющим пользователем 0.3.8.1: НЕ УДАЛЯТЬ, НЕ ЗАМЕНЯТЬ.
039 — ДОПОЛНЕНИЕ, устанавливается отдельным WeiDU только после подтверждения безопасности.

Сделано:
- Не меняет ни одного существующего файла EPS в ZIP и не переписывает 038.
- Использует работающий переключатель F старой 038: только персонажи с BGX38_GUARD=1.
- Пытается защитить любого другого видимого члена партии Player2..Player6, если враг рядом с ним.
- Не выбирает самого охранника (InPartySlot), не отправляет Player1 на охрану группы,
  не прерывает занятые действия (ActionListEmpty), не тратит магию или предметы.
- Сначала защищает раненых (HP<65%), затем остальных явно атакуемых/угрожаемых.
- Добавление через EXTEND_BOTTOM после 038 => 038 защита Player1 получает приоритет.
- Нет нового переключателя, GUI, назначения классов и квестовой привязки.

УСТАНОВКА ПОКА НЕ ТРЕБУЕТСЯ. Если будет принято решение на один контролируемый тест:
0) Отдельный сейв; закрыть Baldur/InfinityLoader/другие WeiDU.
1) Распаковать ZIP в отдельную папку ВНЕ игры.
2) BGXAI39_START.cmd > 3 - status; должны быть BGX38 baseline installed True, BGX39 installed False, Windows process gate CLEAR.
3) BGXAI39_START.cmd > 1 > YES. Только если BGX38 последний WeiDU мод.
4) После успеха — одна лёгкая сцена защиты спеллкастера/лучника при неатакующем EPS.
5) Откат 039 > 2 > YES только если 039 последний установленный мод. Никогда не откатывать 038 до 039.

Важные ограничения: InPartySlot, HPPercentLT на других слотах, bottom priority и ProtectObject
должны пройти настоящую проверку WeiDU/EEex/игры. ProtectObject длительный и может
продолжать ранее выбранную цель, пока не завершится / не будет отдан ручной приказ.
Порядок Player3,4,5,6,2 фиксирован; это первый групповой перехват, НЕ полноценное
рассуждение о ролях/LOS/бафах/зонах/агро. Враг в радиусе 7 не доказывает агрессию на цели.

Без платных API, без полного клонирования EET, без повторной загрузки архивов.
