# BGXAI 072 — безопасный арбитраж с EPS (SOURCE ONLY)

Дата: 14.11.2026. Следующий безопасный этап **автоматически продолжен после успешной BGXAI 071**, без запроса «делай». **Не установлен.** В игре остаётся BGXAI 066S. 067 — HOLD.

## Проблема, которую закрывает модель

Даже если Lua распознал воина, дуал или оборотня, **это не разрешает** перехватить у EPS действие персонажа. Существующая 067 выбирает цель BCS через `NearestEnemyOf(PlayerN)`, что не гарантирует попадания в того же врага, который атаковал союзника. Скрипт ещё должен сохранить ручной приказ, лечение, каст, песню барда, ловушки и действующую очередь.

## Что сделано

`BGXAI072_EPS_FIRST_ARBITER.lua` — чистая Lua-функция `review(role, threat, eps, proposed, config)`. Нет EEex-хуков, записей игровых переменных, игрового кода, BCS и изменения EPS. По умолчанию **все новые активные функции выключены**; даже при тестовом opt-in результат `CANDIDATE_REVIEW_ONLY`, а `allow_engine_action=false`.

Нужно одновременно доказать:
- выбранный защитник имеет F=ON и проверенную потенциальную боевую роль;
- реальная атака известного врага направлена на члена партии, и известен **точный ID нападавшего**;
- EPS не исполняет ручной приказ, спасающее лечение, заклинание, песню, поиск ловушек или команду в очереди;
- цель для будущего BCS определена именно по **точному ID нападавшего**, а не подставлена через `NearestEnemyOf`;
- каждый названный факт `verified=true` от будущего достоверного источника, неизвестное = запрет.

## Проверки

`texlua test_072.lua` — **66/66 PASS**. В частности подтверждены отказ при живом лечении или критической опасности, непроверенной команде, очереди EPS, недоказанной атаке, чужой атаке, замене цели и отсутствии opt-in. Исходные объекты не менялись. Но это модель, а **не тест в реальном EEex**.

Итог: без проверки очереди EPS и точной цели реальный BCS-перехват **не допускается**. Этот модуль не подключён к игре. До получения подтверждённых engine данных и отдельного одобренного релиза не трогать 066S, 067, `BGXAI_UPDATE.cmd`, `WeiDU.log`.
