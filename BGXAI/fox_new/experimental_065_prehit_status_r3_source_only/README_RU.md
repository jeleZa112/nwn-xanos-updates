# BGXAI 065-R3 — read-only состояние ранних атак, SOURCE ONLY

Дата: 12.11.2026. Установленная версия игры **BGXAI 064**, а 065/R2/R3 только исходники и проверки.

## Для чего

В уже установленной 064 есть глобальный Lua-объект `BGX43Probe`, а его обработчик `EEex_Action_AddSpriteStartedActionListener` фиксирует `lastAttack` по Attack(3), GroupAttack(94), AttackOneRound(105), AttackReevaluate(134) и другим attack-family ID. Подтверждённое попадание записывается отдельно как `lastWeaponHit`.

`BGXAI65_PREHIT_STATUS_READONLY.lua` **не регистрирует новый слушатель**, **не меняет** `M_BX43.lua`/BCS/WeiDU, **не меняет** F, HP или LOCALS. Только выводит в текущей игровой Lua-консоли три диагностические строки `BGX65PRE` о счётчиках, последнем action-start и последнем подтверждённом weapon hit. Данные могут быть старыми и относиться к разным событиям: совпадение actor/victim не доказывает, что цель была достоверно известна раньше удара. Если последний action не распознан, причина показывается явно; `reason=recorded` — пассивное наблюдение, а не успешный активный перехват.

## Как использовать, когда будет естественный бой

1. Не переустанавливать 064, не вызывать специально Шанка и не запускать код через PowerShell.
2. В существующей игровой EEex Lua-консоли выполнить содержимое `BGXAI65_PREHIT_STATUS_READONLY.lua` после обычного столкновения. Прислать скрин `BGX65PRE` при желании продолжить проверку разрешения целей.
3. При `NO_OBSERVER` ничего не переустанавливать, лишь зафиксировать. При `reason=target_unresolved` нельзя подавать активный запрос охраны до попадания.

Тесты: 6/6 нативных Lua 5.4 mock PASS, исходники содержат только чтение `BGX43Probe` и `C:DisplayText`. Это НЕ тест в настоящей игровой консоли. В сумме ранее выполненные 065 (42), R1 (10), R2 (19), R3 (6) = **77/77 mock-тестов PASS**.

Следующее фактическое препятствие: реальная проверка надежности `action_start target` для вражеских атак на союзников, различение `target1` / `target2` / `sprite_target` и давности событий, а затем только безопасная реализация раннего планирования. Никакого активного раннего вмешательства пока нет. Дополнительные 45 тысяч ресурсов не требуются.
