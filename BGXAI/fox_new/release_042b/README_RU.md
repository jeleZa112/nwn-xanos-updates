# BGXAI 042B — ограниченная автоатака + приоритет охраны (ЭКСПЕРИМЕНТ)

Версия исходного кандидата: 09.11.2026. Пакет предназначен **только** для `C:\Games\BG_EET_FOXX_NEW` с установленными EPS 18.4 + BGXAI 041. Исходный `BDDEFAI.BCS` должен побайтно соответствовать SHA256 `86d80953be464a3f10da8e1dc031b907801860b7f1f15b3ea6fb9d25e485f3f5` (2 229 760 байт), иначе запись блокируется.

## Изменение

- 11 существующих блоков `ProtectObject` передвинуты перед двумя штатными блоками обычной атаки EPS; условия защиты остались прежними (`ActionListEmpty`, BGX38_GUARD и т. д.).
- Только 2 штатных `Attack()` меняются на `AttackOneRound()`, чтобы обычная автоатака после одного раунда освобождала очередь для повторной оценки угроз.
- Все остальные блоки, действия F и иконки 041, управление заклинаниями, песнями и предметами не изменяются. Новый BCS имеет SHA256 `8602e8853a9c0e8b1bd5733021e6dd9c9ac73e03beb6c9900ef6ebd09dacb9a0` (2 229 764 байта).

## Безопасность

Единственный разрешённый способ установки — **прежний** `BGXAI_UPDATE.cmd` через отдельный пункт после read-only preflight и введения точного `YES`. Нельзя вручную копировать BCS или запускать комплектные скрипты вне контролируемого меню. Перед любыми записями в игру локальный установщик проверяет SHA256 всех исходников, наличие 041 последним в WeiDU.log, путь к EET и отсутствие запущенных Baldur/InfinityLoader/WeiDU. Внешний резервный каталог: `%USERPROFILE%\Documents\BGXAI42_SAFE_BACKUPS` с BCS, WeiDU.log, chitin.key, русскими TLK; файловая копия проверяется SHA256. Затем WeiDU устанавливает отдельный компонент 042, с собственным стандартным backup. Установка не должна проводиться во время игры.

Откат только штатным WeiDU, когда 042 установлен последним и не перекрыт последующим модом. Перед откатом дополнительно проверяется существование **неповреждённой исходной резервной копии** и сохраняется отдельный pre-rollback snapshot. При неопределённом результате WeiDU — остановка и анализ отчёта, НИКАКОГО ручного насильного восстановления поверх структуры WeiDU.

## Ограничения

- Проведены 50 модельных проверок изменения BCS и 26 проверок установщика на тестовой имитации WeiDU. **Это не реальная компиляция/запуск Windows WeiDU на машине пользователя и не игровой тест.**
- `AttackOneRound()` освобождает очередь лишь после завершения одного раунда, а не мгновенно; ручные приказы не отменяются. До завершения ранее выданной атаки охрана может запаздывать.
- Поведение 042B с реальным EPS 18.4, кастами и песнями барда не доказано в игре. Пункт установки остаётся экспериментальным, запускается только при явном выборе пользователем и `YES`.
- Исходники размещаются в публичной ветке GitHub без игровых BCS/TLK и приватных логов. Рабочую 041 никакая загрузка исходников не меняет.

## Проверки до нажатия на установку

Использовать только меню прежнего обновлятора: сначала опция read-only статуса / dry-run; после подтверждённого результата — отдельная экспериментальная установка. Если ошибка / `REVIEW_WEIDU`, не повторять автоматически, прислать текст ошибки и путь к отчёту.
