# Русские броски атаки — реальный путь подключения

Стандартные `попадание`, `промах`, `критическое попадание` в уже проверенном русифицированном TLK переведены. Другое дело — расширенный расчёт `Extra Combat Info`, который может формироваться непосредственно движком и не находиться в TLK.

## Чтобы увидеть данные в игре

1. В моде **Reveal Hidden Gameplay Options** доступно **Show extra combat info**: Настройки → Игровой процесс → Обратная связь → Сообщения. Если уже включено, ничего менять не надо.
2. Отдельно включить обычные «Броски атаки / To-hit rolls», чтобы журнал показывал d20 и суммарную поправку.
3. Чтение из `baldur.lua` без записи: `py -3 feedback_status.py --baldur-lua "ПУТЬ_К_Baldur.lua"` (не вставлять путь, если он ещё неизвестен).

## Понятия без потери смысла

| Надпись | Предлагаемый русский текст | Смысл |
| --- | --- | --- |
| Roll (to-hit) | Бросок атаки d20 | Значение кубика 1–20 |
| THAC0 | ТХАК0 (попадание по КД 0) | Чем меньше, тем лучше атакующий |
| AC / Armor Class | КД, класс доспеха | Чем меньше, тем лучше защита |
| Hit / Miss | Попадание / промах | Результат проверки |
| Attack Bonus / Bonus | Бонус попадания | Может уже быть включён в ТХАК0 — дважды не суммировать |
| Damage Roll | Бросок урона | Это **не** бросок попадания |
| DamageMod | Модификатор урона | Модификаторы силы, эффектов и т. п. |
| Critical Hit | Критическое попадание | Особый результат d20 |

Базовая формула: `d20 + доп. бонус >= THAC0 - КД_цели` (с учётом естественных 1 и 20). В реальном расширенном журнале часть бонусов уже входит в итоговый THAC0 — использовать расчёт только с данными, которые **фактически** выводит EET.

**В игру перевод полей пока не внедрён.** После получения точного живого текста выявить: поля TLK (допустимы через точечный WeiDU `STRING_SET` при строгом совпадении строки) или код движка (потребуется другое решение, возможно EEex). Запрещено массово заменять `dialog.tlk` и `UI.MENU`.
