# BGXAI — новая Foxx, безопасный обновлятор и самостоятельный ИИ

Текущая **рабочая игра**: `C:\Games\BG_EET_FOXX_NEW` (игра с `chitin.key`). Старые локальные файлы BGXAI_UPDATE.cmd находятся в прежней установке и не учитываются как установленная функция в новой. GitHub: `jeleZa112/nwn-xanos-updates`, **только ветка `bg-eet-ai`**. NWN в `main` не менять.

## Что делает новый один файл `BGXAI_UPDATE.cmd`

- Проверяет, что запущен именно в **НОВОМ** каталоге и видит `chitin.key`.
- Получает последний коммит `bg-eet-ai`; скачивает отдельный манифест `BGXAI/fox_new/current.json` на ЭТОМ коммите.
- Сверяет **размер и Git blob SHA** каждого файла; разрешает только исходники, документы и тесты в фиксированных путях.
- Сохраняет файлы в `BGXAI_DEV\` внутри новой игры, где они **не становятся игровыми скриптами автоматически**. Старые версии раздельно резервирует в `BGXAI_DEV\_BACKUP\`.
- Показывает краткий итог; НЕ копирует исполняемые `.BS/.BCS/.TP2/.BAF/.exe/.ps1` в папки игры, не запускает WeiDU и не выбирает новые сценарии персонажам.
- Для новой функции `024` пока допускается **только автономный совет**, без `Attack/RunAway/Spell/MoveToPoint`. Автоматическое управление потребует реальных датчиков и безопасного теста на отдельной EET.

## Статус

Пользователь подтвердил установленную Foxx + SCS 35.21 + EEex 1.2.0 + AutoLoot RU + EPS 18.4; жрец успешно наложил усиления. Барду нулевого уровня пока недоступны заклинания — проверку песни совместно с магией **отложить**, не просить повторить. EPS занимает обычное меню «Улучшенный ИИ» (BDDEFAI), и в новой игре **отличается** от ранее изученного BDDEFAI из старой EET. Нельзя клонировать старый скрипт или отдавать управление старым BGXUN1 v018.

## Новые функции, изучаемые по образцу EPS

- Универсальные независимые переключатели для каждого персонажа: лечение, расходники, защитная магия, песня барда, разведка, скрытность, ловушки, атака, боевые заклинания, навыки.
- Интеллектуальное лечение с учётом подтверждённых HP, доступности заклинания, выбранной цели и учёта **подтверждённого** лечения другим персонажем, без бесполезного дублирования.
- Усиления только когда известны наличие заклинания, возможность применения, активность бафа и безопасность; преимущество безопасных стандартных задержек.
- Поиск/обезвреживание ловушек только при отсутствии наблюдаемых врагов, подтверждённом объекте, вероятности успеха и отсутствии ручного приказа.
- Бард: не срывать песню без доказательства, что можно безопасно возобновить её после заклинания. Проверка отложена до появления заклинаний у персонажа.
- Дальний бой: не запускать старые циклы `AttackOneRound(105) / RunAwayFromNoLeaveArea(355)`; Hybrid 022 пока рекомендует держать позицию за защитником, но **не** исполняет движение.
- EEex 1.2.0 и BG Radar: только проверенные данные, без выдумывания цели врага, происхождения приказа или безопасного пути.

## Важные ограничения

Это НЕ новая установка боевого ИИ. Пока действия остаются за установленным EPS. В папке `BGXAI_DEV` находятся исходники исследования, никакие из них автоматически не включатся. Первый статус «скачано» не означает «прошло в игре». Не публиковать логины, токены, приватные телеметрические журналы. Проверка на Windows и WeiDU выполняется отдельно, до любого переключения игрового ИИ.
