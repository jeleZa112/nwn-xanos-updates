# BGXAI 064 — отдельный безопасный пакет WeiDU (SOURCE ONLY)

**Статус:** код установщика и отката подготовлен; в EET НЕ УСТАНОВЛЕН. Рабочая BGXAI 061 сохранена.

## Подтверждено на компьютере пользователя

- BGXAI 061 — последний в WeiDU, BCS SHA db0fcba4678b00defa2ed7887b57c0d4207effc064891aeb9a0d7dcc1a1a6b0b.
- Lua 061 SHA fd39d23dc722b549c2af1eaf065541b2ed358a9714f2636b8cab4e45fe7dcec5.
- Пункт 71: `064_SOURCE_ONLY_PREFLIGHT_PASS`, `game_written=false`.
- В игровой консоли `BGX64 AREACHECK true true`: `EEex_UDEqual` работает на двух находящихся в одной области персонажах. Внутри обработчика удара отдельно не измерено.

## Что делает пакет

- Lua 064 содержит ровно четыре проверенные замены к исходнику 061 и один существующий выборщик F-охранника; BCS и EPS не меняются.
- `BGXAI64_INSTALL_SOURCE_ONLY.py preflight` — читает текущие WeiDU/BCS/Lua, сверяет зафиксированные SHA256 и строит кандидат только в памяти.
- `install --yes --confirm INSTALL_BGXAI_064` — ПОСЛЕ отдельного подтверждения в едином BGXAI_UPDATE.cmd; требует Windows, точную папку игры, закрытую игру/InfinityLoader, BGX61 последним, SHA256 и внешнюю проверенную копию. Затем WeiDU обновляет **только** Lua `override/M_BX43.lua`.
- `rollback --yes --confirm ROLLBACK_BGXAI_064` — проверяет, что BGX64 последний, и возвращает исходную 061 через WeiDU с собственной предварительной резервной копией.
- Дополнительная проверка запущенных процессов прямо перед WeiDU исключает простой сценарий гонки при подготовке.
- Команды статуса и предпроверки не изменяют игровые файлы; загрузка исходников в `BGXAI_DEV` в будущем возможна через единый обновлятор.

**Не запускать установщик вручную.** Команда с подтверждением предназначена для отдельного опционального меню существующего `BGXAI_UPDATE.cmd`, после проверки нативного PowerShell-кода. Пока новый пункт ещё не активирован.
