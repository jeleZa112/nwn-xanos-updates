# BGXAI 042B — установочный кандидат SOURCE ONLY (НЕ ПРОВЕРЕН В EET)

Сборка создана 08.11.2026 на основе реально полученного BCS пользователя EPS 18.4 + BGXAI 041. В игре ничего не установлено и не изменено.

**НЕ распаковывать в корень игры и НЕ запускать `BGXAI42_INSTALL.py` вручную.** Этот ZIP — исходники для рецензии и последующего подключения к уже существующему однофайловому `BGXAI_UPDATE.cmd`. В этой поставке новый пункт меню в рабочий обновлятор пока **не** добавлен.

## Принцип действия

- Программа проверяет живой BCS: `SHA256 86d80953be464a3f10da8e1dc031b907801860b7f1f15b3ea6fb9d25e485f3f5`, 2 229 760 байт и 1057 CR-блоков.
- Перед двумя обычными ветками autoattack EPS ставит 11 исходных (неизменённых) блоков защиты; обычную `Attack()` меняет на `AttackOneRound()` только в двух ветках.
- Подготовленный BCS: 2 229 764 байта, `SHA256 8602e8853a9c0e8b1bd5733021e6dd9c9ac73e03beb6c9900ef6ebd09dacb9a0`.
- При установке строго требуются BGX41 последним в WeiDU.log, исходный точный BCS, закрытые Baldur/InfinityLoader/WeiDU, свободные собственные имена. Только после подтверждения YES: внешняя резервная копия BCS, WeiDU.log, chitin.key и русских TLK. Далее stage BCS и запуск существующего пользователя Windows WeiDU для `setup-BGX42.tp2` с `COPY` оригинального скомпилированного текста. Ошибки дают `REVIEW_WEIDU` без слепой перезаписи game files.
- Откат через WeiDU разрешён лишь когда BGX42 последний мод, текущий BCS равен ожидаемому и прежний мод не перекрыт последующими установками.

## Проверки и честные границы

- 50/50 офлайн-проверок собственно приоритета и ограниченной атаки; 20/20 офлайн-тестов установщика с mock-WeiDU, всего **70/70**. Файл установки в реальной Windows EET и компиляция/переход на `BGXAI_UPDATE.cmd` **НЕ подтверждены**.
- Код не вызывает ClearActions(), не принуждает касты и не меняет игровую 041 до явного установки пользователем. Старые вручную назначенные длительные Attack из сохранений не обязательно завершатся через один раунд. Разное целеполагание EPS после AttackOneRound и взаимодействие с песнями барда требуют одного контролируемого игрового теста после рабочего релиза.
- Из публичного GitHub НЕ распространяется пользовательский BCS, только собственный код/TP2/README/манифест. Точный пользовательский бинарный BCS остаётся в защищённой Library.

## Далее

Рецензировать параметры WeiDU `--force-install`, `--force-uninstall` и TP2 COPY на точной версии инструмента, затем добавить только проверенный релиз с отдельным статусом и explicit YES в ранее установленный один `BGXAI_UPDATE.cmd`, предварительно сверив pin и SHA. Никаких новых CMD не требуется.
