# BGXAI 048 — подтверждение фактического попадания (READ-ONLY)

Источник: Bubb, форум Beamdog, *General Mod Questions*, стр. 66. `AttackReevaluate` может содержать объектный селектор с `m_Instance=-1` вплоть до выполнения. **Нельзя** объявлять такое действие нападением на выбранного члена отряда по одному лишь `m_acteeID` или `m_acteeID2`.

В EEex **v1.1.7** присутствует `EEex_Sprite_AddBlockWeaponHitListener`, callback получает `context.attackingSprite` и `context.targetSprite`. Дополнительный пассивный слушатель запоминает только пары «враг → член партии», когда движок уже достиг проверки попадания. Callback всегда возвращает `false`, включая исключения. Никакого блокирования попаданий, отмены урона, постановки AI-действий, смены приказов, изменения скриптов BCS.

**ВАЖНО:** событие `NONPARTY_WEAPON_HIT_ON_PARTY` означает вызов предударного/попадательного обработчика, **не каждую начавшуюся атаку**, не промахи, не магический урон и не обязательно фактически прошедший урон. Для раннего перехвата агрессии потребуется независимый механизм. Не путать эти уровни наблюдения.

Оригинальный 047-слушатель начала действия сохранён; если его цель неразрешена, событие отклоняется без домыслов. При попадании записывается отдельное событие с прямыми ID актёра и жертвы.

## Безопасность

Допустимое изменение — только `override/M_BX43.lua` через WeiDU. Требуется установленный 047 последним, точная SHA256 старого Lua, неизменные 042B BCS/043P/044/045 Lua, отсутствие запущенных процессов, `YES`, резервная копия и строгий откат. В игре ничего не изменено этим архивом. Проверки только офлайн, перед установкой нужен preflight.

После установки запустить игру через InfinityLoader, при одном попадании открыть Lua-консоль и ввести:

```lua
local s=BGX43Probe.snapshot(); C:DisplayText("VER="..s.version.." HITS="..s.weapon_hit_calls.." EVENTS="..#s.events.." REGISTERED="..tostring(s.weapon_hit_registered).." HIT_ERRORS="..s.weapon_hit_errors)
```

Не устанавливать новую версию без подтверждённого source manifest и preflight. Не менять 047/042B вручную.
