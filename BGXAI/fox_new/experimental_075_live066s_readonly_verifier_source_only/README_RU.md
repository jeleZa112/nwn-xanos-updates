# BGXAI 075 — безопасная проверка живого BCS 066S (исходник, НЕ установка)

Дата 14.11.2026. В самой игре по последнему подтверждённому сообщению пользователя BGXAI **066S**, но эта проверка **не выполнялась на его ПК**. Вход — только локальный BCS, который программа **читает**. Выход — только JSON в консоль. Программа не устанавливает моды, не пишет в игровой каталог и не управляет персонажами.

## Какую ошибку предотвращаем

Старый снимок BGXAI 041 содержит 1057 BCS-блоков и штатные EPS-настройки, но не позволяет подтвердить состояние текущей установленной 066S. Для настоящей 066S разработана отдельная **строгая SHA-проверка** и побайтная реконструкция прежней 064 путём исключения 11 вставленных блоков. Код не имеет отключаемого флага проверки хешей в CLI; на любом несовпадении выводит `BLOCKED_NO_GAME_CHANGE`.

**Pinned expected:**

- Live 066S `override/BDDEFAI.BCS`: SHA256 `fb435d82e6c3e0ebea1d6a9532753921bd5411d70ac0677dc1fd8ec483380476`;
- Baseline 064/061: SHA256 `db0fcba4678b00defa2ed7887b57c0d4207effc064891aeb9a0d7dcc1a1a6b0b`;
- 1088 блоков 066S; 1077 старых; 11 новых в позиции после индекса 1050. Проверяются действие и маркеры 061-получателя, 066S-лечения/самозащиты, присутствие EPS и F.

## Как использовать при необходимости

Если потребуется убедиться, что твоя установленная 066S соответствует исходной, можно выполнить в PowerShell (Python уже имеется на твоём ПК):

```powershell
py -3 verify_066s_live_075.py --bcs "C:\Games\BG_EET_FOXX_NEW\override\BDDEFAI.BCS"
```

Скрипт лишь напечатает JSON. Ничего не устанавливать, не использовать `INSTALL_BGXAI_067`. Из-за возможных последующих обновлений (если SHA BCS другой) будет **BLOCKED**, что правильно; нельзя отключать защиту или пытаться «исправить» файл самостоятельно.
