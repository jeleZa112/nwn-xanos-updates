# BGXAI 057 — только исходный код диагностики, не установлен

Состояние: SOURCE ONLY. Не копируйте M_BX57.lua вручную в override и не применяйте поверх установленной 056. Нужен отдельный проверенный WeiDU-инсталлятор с backup/rollback и SHA-сверкой 056. По умолчанию не меняет игру.

Цель: вывести при Ctrl+Alt+F10 счётчики установленного модуля 056 без Lua-консоли и без повторной схватки с Шанком. Читает BGX43Probe.snapshot(), затем только LOCALS F и BGX52_REQ_SLOT/EXPIRE/COOLDOWN у спутников. Не пишет в игровые LOCALS, не отправляет боевые действия. Никаких платных API.

Коды: H = вызовы weapon-hit hook; HE = ошибки; PREP = подготовленные Lua запросы; ATT = попытки; GE = ошибки сигнализации; last = последнее решение; rejects = два ведущих отказа; F = режим охраны; Q = запрос на защиту; MOD = модальное состояние; EX = сырой срок запроса; CD = сырой cooldown. Встроенные числа времени не интерпретировать как секунды без дополнительных проверок.

Важно: live Lua счётчики обнуляются после нового запуска игры; исторический эпизод Шанка нельзя восстановить через новый запуск. Сейчас в установленной игре уже имеется BGXAI 044 на Ctrl+Alt+F11 — сначала проверить этот безопасный существующий hotkey в любом загруженном сохранении. Нажатие F11 не проверяет PREP/ATT, но даёт свидетельство о загрузке Lua. Не обещать работу 057 до реального теста на Windows/EEex 1.2.0.

Проверки для выпуска: синтаксис Lua 5.4 (не означает LuaJIT 2.1 runtime), mock горячей клавиши и отсутствия игровых команд, строгая хеш-верификация источника. Никаких изменений BGXAI 056 / BCS / EPS / SCS / NWN.
