# BGXAI 055 — независимая проверка BAF настоящим WeiDU 251

Причина: ранее 054-R1/R2/R3 тестировались на подменённых процессах и не подтверждали фактический запуск компилятора. Повторять бесконечно пункт 54 на компьютере пользователя недопустимо.

Проверка использует официальные архивы релиза WeiDU v251.00 на GitHub, сверяет размер скачанного архива и SHA256 проверяемого BAF, запускает настоящий бинарник WeiDU в GitHub Actions на Windows и Linux, **без игры**, с опциями `--nogame --no-auto-tp2 --no-exit-pause --noautoupdate --parse-check BAF`.

Она доказывает корректность синтаксического разбора BAF **только при успешном отчёте CI**. Она не доказывает разрешение IDS, компиляцию BCS для реальной EET, игровую реакцию охраны или исправность запуска 054 в конкретной сборке. Не устанавливает TP2, не меняет BCS/TLK/WeiDU.log и не требует действий пользователя.

Статус до получения CI: НЕ ПРОВЕРЕНО НА НАСТОЯЩЕМ WEIDU. Нельзя писать «успешно» лишь потому, что workflow создан.
