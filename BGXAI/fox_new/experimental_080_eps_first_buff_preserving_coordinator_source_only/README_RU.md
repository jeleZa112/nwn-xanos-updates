# BGXAI 080 — EPS-first coordinator, SOURCE ONLY

14.11.2026. Текущая установленная версия Baldur's Gate EET Foxx — **BGXAI 066S**, SCS 35.21, EPS 18.4 и EEex 1.1.7; эту игру проект не меняет. BGXAI F-охрана — отдельная наша функция, не штатный переключатель EPS.

## Задача

Не заменить уже работающие автобафы, лечение, заклинания, песни барда и управление EPS. BGXAI 080 объединяет офлайн-решения 072 (потенциальная охрана) и 078 (выбор лекаря), чтобы одному актёру не назначать одновременно лечение и охрану. Если EPS занят неизвестным действием (включая любое заклинание или баф), решение — HOLD. **Не нужна таблица названий бафов:** любая непустая очередь и любой текущий action, кроме подтверждённого IDLE, являются запретом для нового задания.

Модуль `BGXAI080_EPS_FIRST_COORDINATOR.lua` ничего не исполняет в игровом движке: `orders_sent=0`, `locals_written=0`, `engine_dispatch=false`; по умолчанию opt-in выключен. Даже `ADVISORY_COORDINATION_ONLY` означает только предложение. Требуются независимо проверенные факты об EPS, очереди, команде игрока, реальном нападающем и наличии лечения. 079 пока не доказывает кастабельность заклинания и не является подтверждением пригодности лекаря.

## Исходное подтверждение EPS

Оригинальный сохранённый пользователем BCS версии 041 (SHA256 `86d80953be464a3f10da8e1dc031b907801860b7f1f15b3ea6fb9d25e485f3f5`) прочитан строго read-only: 1 057 блоков. В нём присутствуют `MO_BUFF` в 190 блоках, `MO_LONG_BUFF` в 90, `MO_SOLOBUFFING` в 2, `MO_HealCast` в 11, `BDAI_ATTACK_MODE` в 60. Один блок может содержать несколько разных маркеров. Это **подтверждает наличие правил в 041, но не выполнение бафов и не полный состав текущей 066S**. Подлинный текущий BCS 066S был подтверждён пользователем в 075/076R1, но не был скопирован в пакет 080.
