# BGXAI 0.6.27 — инструкции и критерии приёмки установки профилей (EET/Insane)
Дата 2026-11-03. Статус: ОПУБЛИКОВАННЫЙ ПИЛОТ, реальная Windows/WeiDU компиляция пока НЕ ПОДТВЕРЖДЕНА.

## Новые профили, НЕ привязанные к имени или месту портрета
- BGXRANG ← BGR002.BAF → BGXRANG.BS, Imoen Fighter/Thief/ranged, обнаружение ловушек при безопасной остановке и навыке TRAPS>0. Не включает взлом, обезвреживание и кражи автоматически.
- BGXSCOUT ← BGS002.BAF → BGXSCOUT.BS, Montaron Fighter/Thief/cautious stealth+close melee.
- BGXCAST ← BGC002.BAF → BGXCAST.BS, Xzar Mage/Conjurer or Cleric/Mage if SCS racial override; uses memorized Mirror Image, Blindness, Magic Missile, Cure Light only if actually prepared and permitted.
- BGXHEAL ← BGH002.BAF → BGXHEAL.BS, Fighter/Cleric or other divine-capable class; target ally or self when wounded, keep selected weapon.
- BGXGRP and BGXTANK are identical to previous 0.6.26 sources; main player remains under manual script or can select any desired role.

## Установка через прежний CMD
1. Сохранить игру и **полностью закрыть Baldur's Gate/InfinityLoader**. Не запускать WeiDU поверх открытого процесса. На всякий случай оставить отдельный резервный сейв; не удалять старые.
2. В корне игры запустить **только существующий `BGXAI_UPDATE.cmd`**. Результат должен содержать `Target BGXAI 0.6.27-role-profile-install-pilot`, `BGXAI v0.6.27 VERIFIED ACTIVATION SUCCESS`, `VERIFIED ACTIVE` для всех 6 файлов и `SUCCESS`.
3. Если `FAILED`, `WeiDU FAILED`, нет маркеров или не появился сценарий — **не назначать** новый профиль, прислать только `BGXAI_UPDATE.log` / `setup-BGXAI.DEBUG` (без персональных путей при желании); не переустанавливать многократно. Установщик пытается восстановить ранее скопированные BCS/BS; откат WeiDU metadata не полностью доказан.
4. Зайти через `InfinityLoader.exe`, открыть лист персонажа → Сценарий: проверить наличие `BGXRANG`, `BGXSCOUT`, `BGXCAST`, `BGXHEAL`. Назначить профиль в соответствии с **фактическим** выбранным классом и ролью, а не именем.
5. Начать с **одного** ИИ-персонажа и отдельного сохранения в безопасном месте. Включить ИИ для него, посмотреть `BGXRANG V02` или соответствующую строку. Тест: нет постоянной смены лука на melee; FindTraps включается вне боя при пустой очереди, ручной взлом не прерывается; профиль не сбрасывает атаки каждый скриптовый такт. Затем добавить остальных.
6. Приватный `BGXAI_LIVE.cmd` 0.4.4 можно оставить: он read-only, но F9/reload boundaries и manual vs AI origin пока не определяются надёжно. Детекторы считают подозрения, а не доказанные ошибки бота.

## Проверенное и не проверенное
- Источники/манифест GitHub проверены по именам, маркерам, JSON и BAF-блокам; 7/6/9/7 блоков профилей, PowerShell-скобки сбалансированы, backup и rollback код остался. **Это не реальный компилятор**.
- Нет достоверного общего BAF-объекта `NearestLockedContainer` / безопасного перечисления всех доступных замков. `PickLock(Object)` и `RemoveTraps(Trap)` существуют, но открывать неизвестный объект/сюжетную дверь без подтверждённой цели нельзя. Полный автономный взлом/обезвреживание требует проверенной EEex интеграции с явным разрешением пользователя.
- Все игровые сценарии необходимо проверить в реальной игре до обозначения "стабильные".
- Код размещён ТОЛЬКО в GitHub `jeleZa112/nwn-xanos-updates`, ветка `bg-eet-ai`. `main` NWN не менять.
