# BGXAI — постоянная архитектура одного обновлятора V2

## Что решено

Оригинальный `C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd` остается **единственным** запускаемым файлом пользователя. Вместо разрастания `BGXAI_SYNC.ps1` до лимита 80 000 байт V2 использует небольшой постоянный диспетчер `BGXAI_HUB_V2.ps1` (~12 КБ) и `MODULES_V1.json`. Для последующих задач добавляется новый SHA-прикрепленный модуль и запись в манифест; **не нужно добавлять номера меню прямо в CMD / главный PS**.

Старые пункты **1–179 не переписаны**: точный исходник из коммита `f2827f25da5a01215fcbdc0b9a48e3900d654384` сохранен в `BGXAI_SYNC_LEGACY_F282.ps1` с ТОЛЬКО передачей выбора и закреплением исходного старого коммита. Старый пункт **179** и R47 доступны через этот модуль. Новые номера 180–899 управляются манифестом.

V2 доступен как **однократная замена того же самого CMD**. Исходный `BGXAI_UPDATE.cmd` в GitHub и его канал `BGXAI/fox_new/BOOTSTRAP_PIN.json` пока **сохранены без изменения**, чтобы не нарушить многочисленные ранее утвержденные CI-контракты и оставить обратный путь.

## Установка один раз

1. Игра не запущена. Сделать резервную копию существующего `BGXAI_UPDATE.cmd` вне основной папки или переименовать в `BGXAI_UPDATE.cmd.bak` — **не запускать резервную копию как второй обновлятор**.
2. Скачать [выпуск одного CMD V2](https://raw.githubusercontent.com/jeleZa112/nwn-xanos-updates/9412957ffc7d9f717a207fbb381add19afa18795/BGXAI/UPDATER_V2/BGXAI_UPDATE_V2_RELEASE.cmd) из **неизменяемого** коммита и сохранить в `C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd` — строго то же имя и расположение.
3. Запускать только `BGXAI_UPDATE.cmd`. Первый сетевой запуск получает `BOOTSTRAP_PIN_V2.json`, проверяет SHA-256 / размер / commit загружаемого V2 HUB и записывает проверенный immutable lastgood cache в `%LOCALAPPDATA%\BGXAI_UPDATER`. Если скачать ничего не получилось и ранее проверенного кэша нет — **STOP**, никакого запуска непроверенного кода.
4. При последующем отсутствии сети CMD восстанавливает ТОЛЬКО последнюю успешно SHA-проверенную версию модуля из кэша (проверка размера/SHA/ссылок). Меню старых функций по-прежнему работает после первой загрузки legacy-модуля. Сетевой тайм-аут ограничен 15 сек на хост (RAW + CDN).
5. При необходимости вернуться к V1: закрыть игру, восстановить старый `BGXAI_UPDATE.cmd` из личной копии (или зафиксированного исходного коммита). Моды/игра с этой операцией не устанавливаются и не откатываются.

### Подписка на новые функции без нового обновлятора

`BGXAI/UPDATER_V2/MODULES_V1.json` содержит только номера, режимы, пути, неизменяемые commit id, длины и SHA-256 ресурсов. Диспетчер проверяет **каждый** файл перед временным запуском, хранит в контент-адресуемом кэше, запрещает выход за предопределенный префикс и не читает/не исполняет случайные файлы из override. Только явно выбранный модуль может запуститься, установка игровых модов НЕ является действием по умолчанию, а защищенные режимы требуют точного typed согласия и самостоятельного безопасного механизма установки и отката.

**Пункт 180:** `BGXAI_MODULE180_SAVED_PARTY_CATALOG_RO.py` — проверенный READ ONLY модуль. Повторно использует `BGXAI_GAM_INVENTORY_RO_V1.py` и оригинальный `BGXAI_WEAPON_NATIVE_ITM_R3_RO.py`, из последнего существующего `BALDUR.GAM` получает инвентарь партии и из текущего KEY/BIFF/override — характеристики предметов. Создает пассивную таблицу Lua/отчет в `Documents\BGXAI_LIVE_REPORTS`, не меняя игру, скрипты, сохранения, EPS, WeiDU и текущую атаку. Если EET использует неподтвержденную версию GAME/CRE, нет сохранения или ресурсы отсутствуют — сообщает HOLD. Сохраненный инвентарь НЕ считается live; реальный выбор/equip ждёт независимой проверки R37/R35/EPS.

## Доказательства и границы

- Строгое восстановление старой PowerShell-логики через отдельный неизменяемый модуль: никаких ложных изменений старого 179.
- Windows PowerShell 5.1 и Ubuntu: автоматические тесты корректности манифеста, pin SHA, трех ресурсов пункта 180, десяти случаев GAM+R3, отрицательных кейсов.
- Новая CMD-ветка офлайн-загрузки проверена на изолированной Windows CI, включая имитацию отсутствующей сети, отсутствующего доверенного кэша и измененного скрипта.
- **Не заявляется бесконечная гарантия:** если изменится формат манифеста, PowerShell/Windows или каналы GitHub, понадобится миграция. Однако для расширения функций BGXAI больше не нужно переписывать 80-КБ загрузчик или создавать новые CMD.
- **DEPLOY на компьютер пользователя: НЕТ, пока он один раз не заменит CMD. LIVE AUTOEQUIP: НЕТ.** Текущие моды EPS/SCS/R47 не изменены публикацией.

Первоочередная дальнейшая разработка: R3/R35/R13/V4 источник для альтернативного APR/THAC0 и подтвержденная безопасная граница смены оружия, затем guarded install через модуль в том же V2 меню — не второй updater.
