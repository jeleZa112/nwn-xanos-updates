# BGXAI — точное декодирование сырого ключа APR (SOURCE ONLY)

Реальная проверка TD15 23.11.2026: лук/стрелы, `m_nNumberOfAttacks=2`; меч, `m_nNumberOfAttacks=7`. В таблице IESDP [BG(2)EE opcode #1](https://iesdp.bgforge.net/opcodes/bgee) значение ключа `2` означает **2 APR**, а ключ `7` — **1,5 APR**, а НЕ 7 APR. Порядок чисел не является порядком скорости атаки.

`apr_key_decoder_ro.py` не подключён к игре, не имеет доступов к EEex, WeiDU, файлам или сетевым ресурсам и не выбирает оружие. Все неизвестные ключи возвращают HOLD. Поле `effective_apr_verified=False` всегда остаётся false: реальные временные эффекты, дополнительные атаки, класс, двуручное оружие, боеприпасы, способ использования и APR других слотов необходимо подтвердить отдельно.

Тесты: `python -m unittest -v test_apr_key_decoder_ro.py`.

Дальше: измерение APR конкретного доступного слота и подтверждение всех условий выбора оружия; никаких переключений/очередей/приказов до их независимой проверки. Source-only не считается игровым PASS.
