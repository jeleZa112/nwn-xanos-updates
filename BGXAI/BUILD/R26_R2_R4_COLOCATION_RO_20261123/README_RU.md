# BGXAI R26 — состыковка реальных R2/R4 выбранных атак без установки

**SOURCE ONLY / GAME DEPLOY NO / LIVE R26 NO.** Это офлайн-анализ **сохранённой** ранее сессии, не новый наблюдатель в игре. Ничего не пишет на Windows пользователя.

## Что стало точнее

R25 уже выявил в общем журнале 18 зеркальных LUA/LPRINT записей. R26 **повторно использует R25.inspect** и сверяет только нормализованные первичные LUA записи. В реальном журнале соседние записи R2 `SLOTS` и R4 `ACTIVE` совпадают по `seq`, `actor`, `partyIndex`, `actionRaw`, `selectedWeaponRaw`, `selectedAbilityRaw`. Это последовательная согласованность из шести полей; нет единого engine event nonce, поэтому результат **COLOCATED_CANDIDATE, не NATIVE_AUTHENTICATED**.

Успешно обработаны 16 пар: выбранный посох слот38 rawAPR1 — 10, выбранные стрелы слот12 rawAPR2 — 5, меч слот35 rawAPR7 (1.5) — 1. Встречались action IDs 23 — 12, 3 — 4; это **наблюдения начала действий**, а не 16 проверенных фактических попаданий.

**Важно:** наблюдение `selectedWeaponRaw==12` при BOW05 в слот36 само по себе не подтверждает, что именно BOW05 обработал текущую стрелу; подтверждения launcher/ammo пары нет. Точно так же настоящее APR текущего слота не равно APR любого невыбранного. R26 даже для 16/16 совпадений оставляет все `*Authorized` и `nativeEventAuthenticated` FALSE.

## Правила инженерии

- R25 является обязательной независимой проверкой сохранённого байтового потока; R26 не пишет свой парсер зеркал.
- Строгая последовательность SESSION, READY и затем R2→R4; любое несовпадение в шести полях, порядке, APR, пропуск R4, дублирование последовательности, подмена позитивных флагов или актёра — HOLD.
- Код принимает **только bytes**, длина ограничена R25: 2MB; ничего не открывает, не делает EEex вызовов, не пишет в игру, не отдаёт команды.
- Никаких сырых пользовательских журналов в публичном GitHub. Публикуется только агрегированный sanitized verdict.
- Тексты source code и tests в `BGXAI/BUILD/R26_R2_R4_COLOCATION_RO_20261123/`. Оригинальный R25 не изменён.

## Воспроизведение

Запуск GitHub Actions автоматически использует оригинальный `BGXAI/BUILD/R25_CAPTURE_SEGMENT_SOURCE_ONLY_20261123/BGXAI_R25_CAPTURE_SEGMENT_RO.py` как зависимость и тесты 28/28 на **синтетических** fixture. Отдельная локальная проверка использовала реальный сохранённый лог и подтвердила 16/16 пар. Никакого live-испытания в EET на R26 не было.

## Следующее ограничение

Нужно подтверждение engine-level общего event identity, runtime APR других слотов, полной активной effect-цепочки, реальной launcher/ammo пары и происхождения ручной/EPS очереди. Пока возможен только офлайн-анализ выбранного оружия. Для установки нового наблюдателя — отдельное typed согласие, SHA preflight, внешний backup и только существующий обновлятор.
