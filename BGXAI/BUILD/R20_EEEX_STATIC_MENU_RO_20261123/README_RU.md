## При запуске пункта 164
1. Взять строго фиксированный R19 из pinned commit через существующий Get-PinnedBytes, сверить SHA256 и размер.
2. Скопировать во внешний локальный кэш `%LOCALAPPDATA%\BGXAI_UPDATER`, перепроверить SHA256.
3. Выполнить `py -3` только с `--game C:\Games\BG_EET_FOXX_NEW`. Внутренний R19 сканирует только файлы Lua и chitin.key в read-only режиме.
4. Сохранить вывод UTF-8 JSON вне папки игры: `%USERPROFILE%\Documents\BGXAI_LIVE_REPORTS\BGXAI_R20_EEEX_STATIC_<date>.json`. Вывести тот же текст и путь на экран. При статусе HOLD скрипт R19 возвращает exit code 2; это диагностический результат, а не разрешение на установку.
5. Удалить только временную копию Python из кэша; не трогать игровые файлы.

Проверка установленных Lua не доказывает runtime API, безопасного срока жизни `CItem.pRes.pHeader` или способности `sprite:getLauncher`, не включает наблюдателей, не меняет оружие. Даже при EXACT результат — только статическая проверка. Сохраняется `safeToCallGetAbility=false`, `safeToCallGetLauncher=false`.
