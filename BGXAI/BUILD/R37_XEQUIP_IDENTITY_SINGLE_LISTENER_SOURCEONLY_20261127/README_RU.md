## Проверяемое соответствие

В текущем callback передаётся `sprite` + проверка 6 портретных ID через `EEex_Sprite_GetInPortraitID` + R37 текущий action/selection/queue/script context. Снимки считываются дважды, исходный персонаж должен быть portraitIndex=1 / class=3, с единственным `STAF01` в слоте 20, пустым слотом 35, flags=1, charges=[0,0,0]. Входные байты реального GAM уже проверены на предыдущем этапе; **runtime сохранение не аутентифицируется**.

**Отдельная строка `[BGXID]` после прежних `[BGXR27]`, `[BGXR37]`, `[BGXINV3]`** содержит только ограниченный статус и позицию группы; не выводит engine actor ID. Все старые строки событий остаются в исходном коде без изменений. Вся логика READ ONLY, все `armAuthorized=false`, `dispatchAuthorized=false`, `ordersSent=0`, `localsWritten=0` и `safeActionBoundaryVerified=false`.
