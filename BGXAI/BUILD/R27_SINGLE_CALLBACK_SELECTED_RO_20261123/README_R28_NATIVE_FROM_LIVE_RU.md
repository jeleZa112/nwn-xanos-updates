# BGXAI R28 — единый R27 LIVE → R3 native ITM, без установки

Цель: получать характеристики конкретных реальных предметов, уже увиденных в 24/24 доказанных LIVE-событиях R27, из **текущей сборки EET**. Никакого нового синтетического «боя» или новой версии Lua-наблюдателя.

R28 — вход в том же `BGXAI_UPDATE.cmd` через `165 → 6`. Подтверждает WeiDU/PROOF/SHA установленного R27 и закрытие игры; проверяет новый модуль по SHA; проверяет **старый неизменённый парсер R3 по SHA**; берёт готовый журнал R27 и извлекает 4 raw resref (24 последовательных события); читает native ITM, эффекты и 2DA через точно прежний R3. Результат сохраняет только в `Documents\BGXAI_LIVE_REPORTS\BGXAI_R28_NATIVE_FROM_R27_*.json`, **игра не изменяется**.

Локально: тесты R27 и R28. Негативные проверки: иной SHA, повтор SESSION, неверный seq, подмена resref, неустановленный R27, нет данных, запрещённый dispatch. При успешном результате NEXT — анализ конкретных ITM ability и 2DA с проверкой launcher/ammo; только после этого проектировать неразрушающее управление выбором оружия. До этого auto-switch OFF.
