# BGXAI R27 — интеграция пассивного пилота в один обновлятор

**Назначение:** добавить пункт **165** в существующий `C:\Games\BG_EET_FOXX_NEW\BGXAI_UPDATE.cmd` через защищённый backend `BGXAI/BGXAI_SYNC.ps1`, без второго CMD и без ручной подмены игровых файлов.

Пункт 165 загружает из неизменяемого GitHub commit и сверяет SHA256 двух файлов: `M_BGXR27.lua` и `BGXAI_R27_GUARDED.py` (манифест тоже сверяется по форме/версии). Исходники попадают только в `BGXAI_DEV\weapon_r27_observer` и **не устанавливаются** в игру при простом входе в меню.

Внутри пункта 165:

- `1` — статус только для чтения;
- **`2` — preflight READ ONLY (по умолчанию)**: проверка реальных SHA EEex/R2/R4/TD15, последнего WeiDU, существующих файлов, закрытия игры и наличия WeiDU. Если какая-то проверка не пройдена — `R27_STOP`, никаких исправлений «автоматом»;
- `3` — установка только после ввода **`INSTALL_BGXAI_R27_PASSIVE_OBSERVER`**: создаётся внешняя проверенная копия, через WeiDU добавляется **только** `override/M_BGXR27.lua`, игра должна быть закрыта; никакой смены оружия;
- `4` — откат только если R27 последний в `WeiDU.log`, исходник и внешняя резервная копия проверены, а пользователь введёт **`ROLLBACK_BGXAI_R27_PASSIVE_OBSERVER`**;
- **`5` — захват установленного R27, READ ONLY**: проверяет последний компонент WeiDU, SHA игрового Lua-модуля и PROOF, запускает InfinityLoader, записывает одну консольную сессию в `Документы\BGXAI_LIVE_REPORTS\BGXAI_R27_CONSOLE_*.log`. По завершении игры сообщает путь и число `SESSION`/`R27_SINGLE_CALLBACK` маркеров. Установка и откат не выполняются.
- `0` — выход.

Пилот объединяет уже существующие R2 и R4 чтения в одном EEex callback. Максимум 64 события, вывод в консоль/`Infinity_Log`. **Не следует** воспринимать APR выбранного оружия как APR каждого альтернативного слота. Источник действий EPS/manual, launcher/ammo engine pairing и все эффекты всё ещё не подтверждены, `weaponSwitchAuthorized=false`. Выполнять именно этот ограниченный игровой тест, если preflight PASS и пользователь отдельно согласится установить модуль.

**Важная граница:** успешный CI = проверенный исходник/эмуляция установки. Это **не** свидетельство установленной в игре версии и **не** игровой PASS.

## После первого фактического R27 INSTALL PASS

Запустить прежний `BGXAI_UPDATE.cmd` → `165` → **`5`**. Игра запустится через InfinityLoader под захватом консоли. Загрузить существующий тестовый сейв, выполнить 2–3 обычные атаки с луком и/или мечом, штатно выйти из игры. Скопировать JSON-отчёт и прикрепить файл, указанный в `reportFile`. Никаких повторных установок и старых пунктов 163/164. Это проверка выбранного оружия и слушателя, **не** проверка автоматического выбора. Если нет маркеров, статус `R27_CAPTURE_HOLD_CHECK_LOG`; прислать лог для выяснения причин, не повторять тест вслепую.
