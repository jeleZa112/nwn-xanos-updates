# BGXAI — R13: пассивный перехват вывода InfinityLoader без установки

## Причина
В установленном игровом Lua-модуле `M_BGXD13.lua` отчёт сначала пишется через `io.open(...)`; если стандартные Lua-библиотеки ввода-вывода недоступны, он использует `Infinity_Log` / `print`. В стандартной UI-Lua среде Infinity Engine `io`, `os`, `package` не открываются при инициализации, поэтому отсутствие `BGXAI_R13_TARGET_DEFENSE_RAW.jsonl` **не является доказательством незагрузки R13**.

## Новое действие в существующем одном обновляторе

`BGXAI_UPDATE.cmd → 162 → 5 (capture InfinityLoader console; READ ONLY)`.

- Проверяет установленный фикс `M_BGXD13.lua`, точный SHA и текущий `WeiDU.log`.
- Запускает тот же `InfinityLoader.exe` с перенаправлением stdout/stderr в уникальный файл `C:\Users\Drevo\Documents\BGXAI_LIVE_REPORTS\BGXAI_R13_CONSOLE_<UTC>.log`.
- Ожидает выхода из игры для закрытия файла. **Бой не нужен**: достаточно увидеть главное меню, затем выйти из игры.
- Ничего не устанавливает, не удаляет, не изменяет файлы игры и не трогает сохранения.
- Возвращает `BGXTD14_CONSOLE_CAPTURE_CREATED` с путём к файлу либо `BGXTD14_CONSOLE_CAPTURE_EMPTY_HOLD`, если консоль осталась пустой. При неуспешной проверке входного состояния возвращает STOP без запуска игры.
- Успешный захват **не** доказывает, что R13 зарегистрировал хук; решение по фактическим строкам `[BGXTD13]`, `SESSION`, `READY`, `DEFENSE` и ошибкам загрузки.

## Условия

R13.1 и исправление короткого имени R13 должны быть ранее установлены через WeiDU. Действующий последний WeiDU должен быть `BGXTD14`. Данные установки/бэкапа не меняются. Игру и InfinityLoader нужно закрыть перед запуском команды захвата. Используется только существующий `BGXAI_UPDATE.cmd`.

## Проверки

49/49 локальных тестов Python: 35 старых гарантий и 14 новых случаев захвата. Ожидается дополнительный native Windows PowerShell 5.1 CI (фиксировать результат отдельно). Код R13 Lua не меняется.
