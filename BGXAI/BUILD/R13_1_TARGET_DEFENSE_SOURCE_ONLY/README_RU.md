Дата: 22.11.2026. Статус: SOURCE ONLY, OFFLINE TEST PASS; runtime и установка в игре не проверялись.

Основание: пользователь выполнил BGXAI_UPDATE.cmd → 161 → 2. Получено `BGXTD13_PREFLIGHT_PASS_NO_INSTALL`, baselineVerified=5; текущий последний WeiDU — BGXW4. Повторять проверку предыдущей версии не нужно.

Обнаружено в аудите R13: восемь параметров защиты не включали `m_nResistMissile`. В официальном EEex этот показатель существует наряду с `m_nResistPiercing/Crushing/Slashing`; его необходимо наблюдать для стрел, дротиков, пуль и других дистанционных атак. В R13.1 девять полей, а также отдельные проверки `missing/changed` для `m_nResistMissile`.

R13.1 — это только пассивный наблюдатель. Нет выбора оружия, изменения действий, таймера, очереди EPS, установки без буквального токена согласия или автоматической игры. Данные защиты цели не считаются полной защитой, иммунитетами, шансом попадания или проверенным APR.

Изменены вместе: standalone core, runtime wrapper, тестовые фикстуры, guard SCRIPT_SHA и release manifest (версия `0.3.85-R13-TARGET-MISSILE-RO`). Предполагаемое обновление единственного BGXAI_SYNC.ps1 — только версия release TD13, с SHA256 pin после Windows CI. CMD/WeiDU/игра не меняются до отдельного решения пользователя.
