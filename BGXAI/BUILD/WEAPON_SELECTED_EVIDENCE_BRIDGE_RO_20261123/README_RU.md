# BGXAI — связка боевых наблюдений R13.2 + R4 + R1 + R2 (только чтение)

**Статус:** `SOURCE_ONLY`, в игру не устанавливалось. Текущий TD15 оставлен без изменений.

Назначение: сопоставить близко расположенные события **уже существующего** журнала InfinityLoader и декодировать APR только для выбранного на момент атаки оружия. Используется исходный неизменённый `apr_key_decoder_ro.py` из `BGXAI/BUILD/APR_KEY_DECODER_RO_20261123/` (локальная копия для изолированного запуска).

Вход: обычный `.log` с `LUA: [BGXTD13]`, `[BGXW2]`, `[BGXW4]`, `[BGXWP]`. Данные подтверждают чтение полей R13 и текущие характеристики R4/R1; **соседство строк журнала не является подтверждённым нативным идентификатором одного события**. Повторные `LPRINT` игнорируются. Каждое наблюдение содержит ограничения на достоверность и `weaponSwitchAuthorized=false`.

Запуск локальной проверки без игры:

```powershell
python -m unittest -v test_selected_evidence_bridge_ro_v1.py test_apr_key_decoder_ro.py
python BGXAI_WEAPON_SELECTED_EVIDENCE_BRIDGE_RO_V1.py "ПУТЬ_К_СУЩЕСТВУЮЩЕМУ_ЖУРНАЛУ.log"
```

На реальном журнале `BGXAI_R13_2_CONSOLE_20261123T064924087770Z.log` (SHA256 `cebfa573df8fc9e5180ec8cbcfc8b67a865a12c6381394d5dcd511cdf7500945`) получено **4/4** ограниченных наблюдения, 0 `HOLD`: `(slot12, AROW01, sourceAPR=2)` × 3, `(slot35, SW1H04, sourceAPR=3/2)` × 1. Поля защиты цели прочитаны по прежнему R13.2, но их применимость ко всем эффектам/иммунитетам не доказана.

**Запрещено считать доказанным:** фактический APR альтернативных слотов, суммарное влияние всех бафов, пригодность боеприпаса/лука, полный AC со всеми защитами, тип и иммунитет к урону, источник ручной/автоматической команды, пустота очереди EPS, пригодность команды выбора оружия. При отсутствии данных выдаётся `HOLD`, без догадок и без каких-либо команд игре. Исходный журнал не изменяется.

**Следующий шаг по проекту:** получать подлинные пер-слотовые свойства предметов/способностей и доказательства непрерываемости действий, подключать к уже существующему advisory V1/V2, не писать новый алгоритм выбора заново.
