# BGXAI — R16: проверка всех слотов без вмешательства в игру

**Тип:** SOURCE ONLY / READ ONLY; **установка:** отсутствует; **игра/WeiDU/EPS:** без изменений.

## Что сделано

Новый `BGXAI_ALTERNATE_SLOT_EVIDENCE_RO_V1.py` сопоставляет:

1. Проверенные наблюдения R13.2+R1/R2/R4 из `REAL_LOG_EVIDENCE_REPORT_RO_V1.json` (с 4 событиями атак).
2. Снимки текущего оружия/боеприпасов R2 из того же настоящего консольного журнала (15 снимков).
3. Уже существующий **R3 ITM/BIFF** из проекта (`BGXAI_WEAPON_NATIVE_ITM_R3.json`, SHA256 `7ae7555f81b14a784e7866472f14483b02c2d6b707ab6169225e8fec32507304`). R3 сформирован раньше и связан с другим actor ID. Его данные — только *предыдущий снимок статических ресурсов*, а не гарантия актуальных байтов/усиливающих эффектов.

Отчёт — `REAL_LOG_ALTERNATE_SLOTS_RO_V1.json`. Выводит все 4 слота оружия, 4 слота боеприпасов и щит, исходные способности и сопутствующие барьеры доказательности. Отдельно обнаруживает возврат количества стрел 19→20 без заявления, что причина установлена.

### Выводы по исходному логу

| Слот | Ресурс | Статическая базовая способность из R3 | APR из реально выбранного состояния |
| --- | --- | --- | --- |
| 35 | SW1H04 | 1d8, reach 1, speed 5, эффект попадания opcode 146 | 1,5 (raw key 7), только для меча в момент выбора |
| 36 | BOW05 | launcher, дальность 75, speed 6, при надевании эффект opcode 1 с raw value 2 | **Не измерен отдельно для этого слота** |
| 37 | пусто | — | — |
| 38 | STAF01 | 1d6, reach 2, speed 4, двуручное | **Не измерен** |
| 12 | AROW01 | 1d6, raw launcherRequired=1 | 2,0 (raw key 2), *при текущем выборе стрел*, **не доказанное APR других луков** |
| 9 | SHLD03A | Щит, без атакующей способности | — |

Отдельно подчёркнуто: opcode 1 с raw value 2 у BOW05 нельзя без анализа способа применять как +2 APR. Связка BOW05/AROW01 в текущем бою вероятна, но **нельзя** пока считать её проверенной движком парой; щит при двуручном оружии также требует отдельной проверки активного состояния. Статическая базовая 1d8 меча не означает, что критические/усиленные удары автоматически лучше 1d6 стрел: сравнение THAC0, иммунитетов, эффектов, рисков, способности носить и APR альтернатив не закончено.

## Запуск анализа на уже существующих файлах

```bash
python BGXAI_ALTERNATE_SLOT_EVIDENCE_RO_V1.py --log BGXAI_R13_2_CONSOLE_20261123T064924087770Z.log --r3 BGXAI_WEAPON_NATIVE_ITM_R3.json --selected REAL_LOG_EVIDENCE_REPORT_RO_V1.json
```

`apr_key_decoder_ro.py` включён без изменений для проверки кодировки APR (2 = 2,0; 7 = 1,5). Никаких повторных боёв, новых CMD и установки требоваться не должно. Потребность в будущих доказательствах отображается в `blockedBy` для каждого слота.

## Безопасность

- При ошибке входа, SHA, actor, номера действия, выбранного слота, ресурса, эффекта или несоответствии APR: `HOLD`.
- Не переносить характеристики одного персонажа или сеанса в другой; R3 actor=139135050, новый лог actor=139266124.
- Не оценивать *невыбранный* слот по APR текущего выбранного.
- `weaponSwitchAuthorized=false`, `dispatchAuthorized=false`, `priorityEligible=false` для всех слотов.
- Не трогать `BGXAI_UPDATE.cmd`, TD15, EPS, BG_EET_RU, BG Voice RU, сохранения.
