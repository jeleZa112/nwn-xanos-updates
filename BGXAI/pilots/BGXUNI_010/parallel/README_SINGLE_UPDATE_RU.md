# BGXAI 0.1.3 — ОДИН ПОСТОЯННЫЙ ФАЙЛ ОБНОВЛЕНИЯ

Дата: 04.11.2026. **Не требуется скачивать отдельные `BGXUNI_SETUP.cmd`, `BGXUNI_RUN_012.cmd`, ZIP или заменять файлы вручную.**

## Пользователю

1. Сохранить игру. Закрыть Baldur’s Gate и `InfinityLoader.exe`.
2. Запустить старый, давно установленный **`BGXAI_UPDATE.cmd`** рядом с `chitin.key`.
3. На появившемся меню выбрать **`1`** (или нажать Enter): «NEW parallel BGXUN1». Пункт `2` — прежнее обслуживание старых BGXAI 0.6.x, пункт `3` — выход.
4. Дождаться **`[BGXUNI] SUCCESS BGXUNI 0.1.3`**. Если `[BGXUNI] FAILED`, не запускать повторно, показать последние строки `BGXUNI_UPDATE.log` / `setup-BGXUNI.DEBUG`.
5. Только после успешной установки запустить EET, в отдельном сейве выбрать сценарий **BGXUN1** одному NPC. Старый Advanced AI других персонажей оставить как был. Маркер активности в игре: один раз `BGXUN1 V010 READY` над головой.

## Что реально изменено

- **Оригинальный `BGXAI_UPDATE.cmd` в GitHub и на Windows не меняется.** Как и раньше, скачивает актуальный `BGXAI/BGXAI_SYNC.ps1` из ветки `bg-eet-ai` с привязкой к commit SHA.
- В скачиваемом `BGXAI_SYNC.ps1` добавлен режим `1`, который берёт по тому же commit SHA проверенный `BGXUNI_AUTOINSTALL.ps1` и JSON манифест SHA256.
- Установщик скачивает ровно `BGXUN1.BAF` и `setup-BGXUNI.tp2`, сверяет SHA256 и размеры с манифестом, делает резервные копии, запускает `setup-BGXUNI.exe` штатным `--force-install 0` / `--reinstall` **БЕЗ `--tp2`**, проверяет результат компиляции и контрольные суммы `BGXUN1.BCS` / `BGXUN1.BS`.
- Новый мод занимает только своё имя `BGXUN1` и папку `BGXUNI`. `BDDEFAI`, `BGXGRP`, `BGXTANK`, другие BAF и существующие `BGXAI_LIVE.cmd` не затрагиваются при выборе `1`. Существующая ветка `2` сознательно оставлена, она может обслуживать старые BGXAI-профили, поэтому **для параллельного ИИ выбирайте 1**.
- При несовпадении TP2, существующем чужом `BGXUN1.BS`, открытой игре, сбое SHA256 или WeiDU — остановка. При частичном сбое файловый откат, но откат состояния WeiDU/TLK нельзя считать доказанным.

## Ограничения

- BGXUN1 v0.1 — **реальный единый BAF-пилот**, а не завершённый 19-флажковый ИИ с меню EEex. Текущие 11 блоков: осторожный бой, лечение, Mirror Image, опциональная Blindness/Magic Missile, Detect Traps/Hide/BardSong. Нет автоматического снятия ловушек, расходников, поиска пути, союзного AoE или сложного группового арбитра.
- **Тесты — локальные/статические:** 34/34 BAF-тестов (включая 2000 seeded сцен), 7/7 проверок старого CMD и 15/15 тестов новой цепочки + повторная сверка manifest. Нельзя утверждать, что WeiDU успешно компилировал мод на Windows. **Первый реальный контроль — сообщение SUCCESS и `scripts/BGXUN1.BS` на компьютере игрока.**
- При ошибке **не требовать повторно** ранее сохранённые архивы `scripts.zip` / WeiDU.log / три архива EET. Нужен только новый лог конкретного установщика, если ошибки реально будут.
