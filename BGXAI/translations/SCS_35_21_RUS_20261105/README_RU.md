# SCS 35.21 — русское меню установки и недостающие строки

**Для:** Sword Coast Stratagems **35.21** (официальный выпуск Gibberlings Three), EET/BG:EE/BG2:EE, новая установка Foxx.
**Статус:** переведённые файлы собраны, структура проверена автоматически; запуск в Windows/WeiDU и игра пользователя не тестировались.

## Что изменяется

- Полностью русифицирован `stratagems/lang/russian/setup.tra`: все **263** пункта установщика (в исходном русском SCS 35.21 почти все пункты были по-английски; добавлен отсутствовавший @50016).
- Добавлены **8** строк в `stratagems/lang/russian/gameplay.tra` (@24009–@24016: пополнение припасов).
- Добавлены **2** строки в `stratagems/lang/russian/initial.tra` (@50076–@50077: книга «Философия физики»).
- Добавлена **1** строка в `stratagems/lang/russian/leveller.tra` (@55: исходный класс).
- Добавлены **7** строк в `stratagems/lang_som/russian/spell.tra` (@41, @40015–@40017, @40800, @40900, @41008); служебный маркер `NO_CHANGE` оставлен строго без перевода.
- Остальные русские переводы и тексты SCS не переписываются. Исполняемые файлы, `setup-stratagems.tp2`, игровые AI-скрипты, заклинания, `dialog.tlk` и сохранения не изменяются.

## Установка в новой Foxx + SCS

1. Установите/распакуйте **официальную SCS v35.21** в новую папку EET рядом с `chitin.key`, **но не запускайте установщик компонентов, пока перевод не применён**. Если скачан `stratagems-35.21.exe`, откройте его архиватором (например, 7-Zip) и извлеките содержимое. Не извлекайте SCS в старую установленную EET.
2. Распакуйте содержимое этого архива в **корень новой игры** рядом с `chitin.key`. Файлы перевода лежат в отдельной папке `translated`, поэтому распаковка архива сама по себе не перезаписывает игровые файлы.
3. Запустите **`SCS_RU_35_21_INSTALL.cmd`**. Проверяется `VERSION ~35.21~` в SCS, все контрольные SHA256 пакета, структура `.tra` и отсутствие ранее внесённых чужих правок. Оригинальные пять файлов переводов сохраняются в `SCS_RU35_21_BACKUPS\<дата-время>`. При несовпадении условий установка перевода прекращается до перезаписи.
4. Если появилось `SUCCESS: SCS 35.21 Russian setup (263 entries) + 18 missing game entries`, запустите `setup-stratagems.exe` или официальный установщик SCS **из корня новой игры**. Выберите язык **Russian**.
5. При выборе компонентов **НЕ УСТАНАВЛИВАЙТЕ #5000 «Удобный ИИ для отряда игрока»**. В вашей сборке штатный «Улучшенный ИИ» нужен для сочетания песни барда и заклинаний. Остальные SCS-компоненты выбирайте после проверки совместимости новой Foxx.
6. Убедитесь, что EET_end уже завершён: в EET SCS должен ставиться после `EET_end`. После установки сохраните новый `WeiDU.log` для сравнения со старой сборкой.

**Откат до установки SCS:** `SCS_RU_35_21_RESTORE.cmd` восстанавливает последние резервные копии пяти файлов `.tra`. Откат только исходных переводов **не отменяет** уже произведённую SCS запись в `dialog.tlk`; если SCS успели установить, для полного отката его компонентов используйте штатный WeiDU/резервную копию игры.

**Не ставьте пакет поверх уже переработанного/переведённого другого выпуска SCS.** Этот патч предназначен исключительно для исходников официальной 35.21. Если появляется сообщение `not the unmodified official SCS...`, **не заставляйте скрипт продолжать**: он специально защищает чужие правки.
