# ROBLOX_BG_AI — USB HID, аппаратный ввод V1.9.1

**Статус:** исходный код подготовлен и опубликован; оборудование пока не подключено и в Roblox не проверено. Не считать это готовым ботом.

## Зачем это нужно

В логах V1.8.0 оба способа синтетического нажатия Windows не меняли выбор «4 игрока» на «1 игрока», хотя курсор наводился на нужную кнопку. V1.9.1 использует **отдельный USB-контроллер**, который определяется Windows как обычная HID-мышь. Это принципиально иной путь ввода. Никакой гарантии поддержки именно этой игрой нет.

## Оборудование

- **Arduino Leonardo** или **Arduino Micro** с микроконтроллером **ATmega32U4** и USB-кабель для передачи данных.
- Подойдёт совместимая Pro Micro с ATmega32U4 при правильно выбранной плате и загрузчике; у клонов может отличаться порт COM.
- Обычные **Arduino Uno R3 и Nano на ATmega328P** не подходят для стандартной прошивки `Mouse.h` без переделок.
- Отдельные мышь/клавиатура на ПК остаются подключёнными. Для аварийной остановки достаточно отключить USB-контроллер.

## Подготовка один раз

1. В Arduino IDE открыть `ROBLOX_HID_LEONARDO/ROBLOX_HID_LEONARDO.ino`. Выбрать плату **Arduino Leonardo** либо **Arduino Micro**, её COM-порт и загрузить прошивку.
2. Найти COM-порт контроллера в «Диспетчер устройств → Порты (COM и LPT)».
3. В обычной командной строке Windows выполнить `py -m pip install pyserial`. Это единственная новая зависимость, нужная для связи с контроллером.
4. **Обычно порт определяется автоматически:** программа ищет единственную плату Arduino с известным USB VID и всё равно проверяет уникальную подпись прошивки. Если автопоиск не сработал или найдено несколько плат, выполнить `setx ROBLOX_HID_PORT COM7`, заменив COM7 на свой реальный порт. После `setx` закрыть и заново открыть обновлятор.
5. Прежний единственный `ROBLOX_UPDATE.cmd` скачает обновлённый `roblox_monitor.py`. Дополнительных обновляторов создавать не требуется.

Без обнаруженной и подтверждённой Arduino (через автопоиск или `ROBLOX_HID_PORT`) бот **не нажимает кнопки вообще** и остаётся в режиме наблюдения. Предыдущий программный режим можно включить отдельно переменной `ROBLOX_INPUT_BACKEND=SOFTWARE`, но он не доказал работоспособность и **не рекомендуется**.

## Как работает защита

- Перед каждой попыткой бот находит именно окно **Roblox** и проверяет, что оно активно.
- Открывает COM, требует ответ `ROBLOX_HID_V1` и только затем отправляет `ARM ROBLOX_HID_V1`.
- Посылает небольшие **относительные** движения мыши и сверяет положение Windows, пока оно не приблизится к центру нужного элемента.
- Отправляет `CLICK` через HID, ждёт следующий кадр и проверяет цвет рамки **в игре**, а не просто «успех отправки».
- Выполняет `DISARM` и закрывает порт после каждого нажатия. Прошивка дополнительно снимает нажатие и отключается автоматически через 5 секунд без команд.
- При потере фокуса, дрейфе курсора, неизвестном устройстве или неправильной конфигурации прекращает ввод. Запрещена автоматическая UI Navigation с символом `\\`, которая раньше блокировала WASD.
- Работает **только при активном окне Roblox**: использование USB HID двигает системный курсор и не является фоновым вводом, совместимым с работой пользователя за тем же ПК.

## Файлы

- `roblox_monitor.py` — основной бот, версия V1.9.1; COM-мост встроен в него, чтобы сохранить один обновлятор.
- `ROBLOX_HID_LEONARDO/ROBLOX_HID_LEONARDO.ino` — прошивка.
- `ROBLOX_PROJECT_STATE_RU.md`, `ROBLOX_PROJECT_LEDGER_RU.md` — состояние и решения.

## Ограничения

Из этой среды нельзя прошить физическую Arduino и проверить, обработает ли Roblox её USB HID-клик. Результат будет подтверждён только после появления реального оборудования. Автоматическая навигация к площадке, строительство, бой и работа в фоне пока не реализованы. Автоматизация чужих игр также может регулироваться правилами самой платформы и отдельной игры.

## Проверка исходников
- Локально выполнена проверка C++-синтаксиса прошивки с заглушками Arduino API (`g++ -fsyntax-only`) — успешно; это не эквивалент полноценной сборки под ATmega32U4.
- В ветке есть `.github/workflows/roblox-hid-check.yml`: проверка Python-синтаксиса и компиляция Arduino Leonardo в GitHub Actions. Не объявлять обе проверки пройденными, пока не получено подтверждение соответствующего запуска.
