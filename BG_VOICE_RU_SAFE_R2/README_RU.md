## Новый реализованный код

`bgvoice_safeguards_r2.py` развивает проверенный R1; **старый R1 сохранён отдельно**.

1. `verify_signed_manifest`: усилена валидация после Ed25519-подписи, убраны `assert`, которые пропадают при Python `-O`; строгие version/commit/sha/path checks. **Реальные подписи релизов и издательский доверенный ключ не созданы/не внедрены** — не включать автоподпись с тестовым ключом.
2. `_safe_relname`: запрещены пути с `../`, DOS-устройства, Alternate Data Streams `:`, UNC, хвостовые точки и обратные слеши. Тесты подтверждают отказ в опасных именах ZIP.
3. `verify_model_bundle(strict_inventory=True)`: отклоняет не перечисленные в доверенном pinset файлы и ссылки, проверяет размер и SHA256 каждого ассета. Дополнительный `inspect_existing_bundle_readonly`: извлекает фактический список файлов, хеши/размеры, но не утверждает доверенность найденной модели.
4. `summarize_batch`: отвергает чужой или опасный Sound ID, проверяет ID/fingerprint/sha/status WAV-sidecar, не выдаёт `WORKER_OK` за `ALL_READY`.
5. `inspect_report_readonly`: CRC, число записей, имена, SHA общего ZIP без его модификации.
6. `build_strict_style_pair`: одинаковый подтверждённый голосовой референс в вариантах A/B, проверка SHA, обязательные флаги Human Approved RU Text + Verified English + Approved Voice; стиль `(control)text` разрешён только при доказанной поддержке установленной библиотеки. Функция **не запускает GPU**.
7. Lock + atomic publish сохраняются из R1. **Не гарантия устранения всех гонок до внедрения одинаковой блокировки во ВСЕ старые ZIP-writers.**
