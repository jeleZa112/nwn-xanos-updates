# BG_EET_RU: строгая связь удар → CMessage → видимая строка (source-only)

Текущая рабочая игра: **V125 (14/14 этапов)**; этот код **не устанавливается в игру** и не меняет `BG_EET_RU_UPDATE.cmd`.

## Что реально сделано
`strict_join_v1.py` — детерминированный fail-closed контракт связывания трёх независимых фактов:
1. Попытка атаки: одна игровая сессия, поток, стековый кадр, порядковый номер, attacker/target, предмет именно этого замаха, HIT/MISS, message pointer и token.
2. Настоящее сообщение: тот же thread/frame/seq/ptr/token, тип ATTACK_ROLL и callsite внутри `CGameSprite::Hit()` `0x39E84B` (другие callsites AddMessage и общую vtable Damage отклоняем).
3. Отображённая строка: тот же token/ptr/seq/attacker/target, уникальный row_id, UI источник и тип ATTACK_ROLL.

Не используем расстояние во времени, текущую экипировку, соседнюю строку, одну vtable или похожий текст как доказательство. Никакого изменения существующего журнала. Возвращаем только `SOURCE_ONLY_CANDIDATE`, а **никогда** gameplay PASS. При неоднозначности вернётся `HOLD`.

## Исполнение
- `python -m unittest -v test_strict_join_v1` — 29 тестов, включая два противника, неверный message ptr, соседнюю строку, повторное использование указателя, отсутствие ABI и чужое сообщение Damage.
- `python strict_join_v1.py <USER_V125_ZIP> --output audit.json` — только чтение архива и создание внешнего файла. Запуск внутри компьютера пользователя **не требуется**: входной ZIP уже проверен при разработке.
- На реальном ZIP от 24.11.2026 статус `HOLD_NO_PER_ATTACK_TO_VISIBLE_ROW_JOIN`: отсутствуют attacker_id, target_id, attack_seq, row_id и собственный UI observer, хотя все восемь существующих проверок памяти V122 прошли.

## Следующая кодовая задача
Установить безопасную точку наблюдения, где можно впервые доказанно получить **оба конца связи**: native CMessage из конкретного `Hit()` и отдельную видимую строку. Требуется доказанная Win64 ABI / EEex JIT owner / SEH-unwind и безопасное восстановление. **До этого** источник V4 `BG_EET_RU_THREAD_FRAME_BRIDGE_V4.lua` остаётся неустановленным, русские названия оружия не добавляем к промахам по догадке. Игровой пилот только с отдельным разрешением, внешними backup и rollback.
