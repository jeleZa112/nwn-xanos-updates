## Правила следующей работы
- Сейчас **на PC пользователя не подтверждён запуск V125**. Из-за отсутствия автоматического обновления в последнем ZIP не просить бесполезно повторять V122. Сначала восстановить *доставку* одного канонического `BG_EET_RU_UPDATE.cmd`, используя прямой файл GitHub при необходимости. Не создавать второй CMD и не изменять игру.
- Если автоматическое обновление raw.githubusercontent.com не срабатывает, допустимо **однократно заменить тот же канонический файл**: скачать `bg-eet-ru/onefile/BG_EET_RU_UPDATE.cmd` из ветки `bg-eet-ai` GitHub и сверить SHA256 с манифестом. Для самостоятельного обновления нужен доступ в интернет к raw.githubusercontent.com; причина отсутствия V124 в ZIP пока неизвестна.
- Только один полный read-only запуск V125, при необходимости с открытой через InfinityLoader игрой, один `SEND_TO_CHATGPT_BG_EET_RU.zip` и новая запись `62_V124_ONE_RUN_BOT.json` с `updater_version=125`.
- Модификация игры/EEex hook только по separate typed approval, SHA, external backup, rollback и доказанной безопасной ABI; не трогать BGXAI, BG Voice RU, сейвы.
- Критерий успеха — реально работающий русский боевой журнал, не количество тестов. Ориентироваться на `bg-eet-ru/ONE_RUN_AUTONOMOUS_POLICY_RU.md`.
