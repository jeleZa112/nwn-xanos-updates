# BG_EET_RU — V160: сообщения об оружии при попадании

**Статус: SOURCE / MODEL TEST PASS. Без пользовательской установки.**

V160 добавляет отдельное видимое сообщение вида **«Оружие при попадании: Стрела (Короткий лук)»** только при вызове существующего EEex callback `EEex_Sprite_AddAlterBaseWeaponDamageListener`. Он вызывается после создания базового эффекта урона при попадании оружием; это не подтверждает, что повреждение действительно прошло через иммунитеты или резисты. Промахи не охватываются. Новая строка **не привязывается к конкретной старой строке `combatLog`**; нет обманчивых связываний по имени, тику, или соседству.

Для `SW1H04`, `AROW01`, `BOW05` названия русские, взятые из фактической русской TLK сборки (V111). Прочее оружие показывает точный RESREF с префиксом «код», пока его локализованное имя не доказано. Источник callback — уже работающий V108. Новых EEex хуков и слушателей нет: V160 оборачивает прежний `BG_EET_RU_WEAPON_EVENT_OBSERVER_V1_OnBaseDamage` и сохраняет возвращаемое значение. Есть защита от рекурсии, отсутствие IO в Lua, лимит 2000 сообщений на сеанс и отключение при недоступном API вывода.

Guarded Python installer (`v160_guarded.py`) **никогда не устанавливает автоматически**; ожидает точный V106+V108 Lua, совпадение SHA действующей игры, EEex, UI.MENU и TLK V159, а также `V108` state. При установке необходимы закрытые Baldur.exe/InfinityLoader/WeiDU, точная фраза `INSTALL_BG_EET_RU_V160_HIT_ONLY`, резервная копия вне игры, атомарное обновление одного файла и последний откат по `ROLLBACK_BG_EET_RU_V160_HIT_ONLY`. На несовпадении всегда SAFE_STOP. Вызов только из **имеющегося** BG_EET_RU_UPDATE.cmd, не отдельный пользовательский установщик.

Проверки: `python -m unittest discover -s bg-eet-ru/hit-only-v160 -p 'test_*.py'`. Имеется Lua 5.4 runtime-mock, который НЕ является запуском EEex в Baldur.exe. Опубликованный V159, если новый этап не подключён, оставляется нетронутым. Runtime, производительность, видимый лог и отсутствие нативных ошибок при `Infinity_DisplayString` **ещё не проверены в игре**.
