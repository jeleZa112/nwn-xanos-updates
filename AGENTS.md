# AGENTS.md — обязательный контроль ошибок и прежней работы

Применять к любому кодовому заданию, тесту, переводу, документации и при продолжении другого чата. Это инструкции агенту, **не** отдельный реестр ошибок.

**Перед действием (ERROR-READ):** восстановить актуальную контрольную точку проекта; проверить по смыслу функции, не была ли она уже реализована. Открыть единый реестр известных ошибок и доказательства подходящих записей; кратко зафиксировать `ERROR_GATE: CHECKED|PARTIAL|HOLD`, `MATCHED_ERROR_IDS`, `SOURCES_READ`, `DO_NOT_REPEAT`, `NEXT_SAFE_DELTA`. Неполная история — `PARTIAL`, а не «ошибок нет».

**После подтверждённой ошибки (ERROR-WRITE) — обязательно ДО повторного запуска:** найти соответствующий `error_id` и обновить его существующую запись/доказательства; если ошибки ещё не было — добавить ОДНУ новую запись в существующий `project_error_register` с причиной либо `UNKNOWN`, точным логом, запретом повтора и проверяемым условием исправления. Обновить канонический handoff; сохранить отрицательные результаты. `ERROR_WRITTEN: ID + ссылка` в отчёте. Если запись невозможна — `ERROR_NOT_SAVED`, без ложного заявления о сохранении.

Не перезапускать прежнюю неудачную операцию без устранения причины. Разделять SOURCE/TEST/DEPLOY/LIVE и разрешения пользователя. CI проверки ограничены форматом и поддержанными случаями; source PASS не означает успех на ПК, а GitHub Actions не гарантируют блокировку merge без required branch checks.

**Общий реестр и регламент лежат в другой рабочей ветке того же репозитория:** [KNOWN_ERROR_GATES_V1.json](https://github.com/jeleZa112/nwn-xanos-updates/blob/bg-eet-ai/GLOBAL_PROJECT_RULES/KNOWN_ERROR_GATES_V1.json), [GLOBAL_PRIOR_WORK_GATE_V1_RU.md](https://github.com/jeleZa112/nwn-xanos-updates/blob/bg-eet-ai/GLOBAL_PROJECT_RULES/GLOBAL_PRIOR_WORK_GATE_V1_RU.md). Использовать их только после реальной проверки доступности и фактического содержимого. Не путать `BG_VOICE_UPDATE.cmd` на `bg-voice-ru` с установленным более новым обновлятором пользователя; не создавать отдельный CMD. Сохранять одобренные WAV и ручные решения; игровые установки — только с разрешением.
