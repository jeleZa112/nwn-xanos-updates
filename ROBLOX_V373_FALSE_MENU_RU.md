# Roblox V3.7.3 — 09.11.2026

## Последний живой запуск V3.7.2
В журнале AUTOPILOT_LOG(8).txt есть успешные SPAWN_MOTION, NAV_VISUAL_FALLBACK A/W и два сообщения SCENE CREATION_MENU с `modal=False digits=4 create=0.075 cancel=0.276`. Визуальное подтверждение меню отсутствует. Бот остановился из-за MENU_CANDIDATE_NOT_CONFIRMED_6S; матча не было. На пользовательском скриншоте открытого меню не видно.

## Исправление V3.7.3
Старый lifecycle_scene_hint основан на фиксированных областях UI, которые в живом лобби могут выдавать CREATION_MENU, хотя независимый autopilot_menu_features modal=False. Новый контроллер не считает это меню подтверждённым. Только modal=True может создавать кандидата меню; при доказанном высоком purple-показателе сцена остаётся LOBBY_COUNTDOWN_OR_PORTAL, иначе UNKNOWN и безопасный стоп без нажатий. Никакого клика Create без полноценной проверки всех параметров.

Статус: GitHub код обновлён, но Windows / Roblox тест V3.7.3 не выполнялся. Не требовать пользователя повторять длинные видео или бесконечные тесты.
